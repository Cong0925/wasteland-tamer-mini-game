# 游戏启动流程设计

> 本文档记录游戏从启动到进入主界面的完整流程设计

---

## 📋 设计决策

| 决策项 | 选择 | 说明 |
|--------|------|------|
| 流程方案 | 方案A1：标准RPG流程 | 经典RPG体验 |
| 前言方案 | 方案C2：文字式前言 | 简洁，开发量小 |
| 新手教程 | 方案B1：纯剧情引导 | 代入感强 |
| 数据存储 | 微信云开发 | 云端存储 |
| 游戏类型 | 休闲类文字RPG | 关卡难度不大 |

---

## 🎮 完整流程

```
游戏Logo → 文字式前言 → 角色创建 → 新手教程 → 主界面
```

### 流程1：游戏Logo

**功能：**
- 显示游戏Logo、版本号
- Loading动画（废土风格）
- 加载基础资源

**页面元素：**
- 游戏Logo图片
- 版本号文字
- Loading进度条/动画

**跳转逻辑：**
- 资源加载完成后自动跳转到前言页面

---

### 流程2：文字式前言

**功能：**
- 介绍故事背景和世界观
- 营造末日废土氛围
- 支持跳过

**前言内容：**

```
[黑屏，文字逐渐显示]

2040年，环海之国开始向太平洋排放核废水。

2045年，变异海洋生物登陆，沿海城市沦陷。

2050年，核战争爆发，人类文明崩溃。

2060年，废土时代开始，人类在废墟中挣扎求生。

2100年，你从昏迷中醒来...

[系统提示] 你失去了记忆，需要寻找身世线索。

[选择] [开始游戏] [跳过前言]
```

**页面元素：**
- 文字显示区域
- "开始游戏"按钮
- "跳过前言"按钮

**跳转逻辑：**
- 点击"开始游戏" → 进入角色创建
- 点击"跳过前言" → 直接进入角色创建

---

### 流程3：角色创建

**功能：**
- 创建玩家角色
- 选择职业和初始宠物
- 保存角色数据到云端

**角色创建步骤：**

#### 第一步：输入角色名
- 随机生成名字（废土风格）
- 玩家可以手动修改
- 名字长度限制：2-8个字符

**随机名字库：**
```
男性名字：废土行者、荒野猎人、钢铁意志、流浪者、拾荒者...
女性名字：废土玫瑰、荒野之花、钢铁女战士、流浪者、幸存者...
```

#### 第二步：选择性别
- 男
- 女

#### 第三步：选择职业
| 职业 | 特点 | 推荐宠物类型 |
|------|------|--------------|
| 战士 | 近战输出，高生命值 | 防御型宠物 |
| 游侠 | 远程输出，高敏捷 | 攻击型宠物 |
| 法师 | 元素魔法，高智力 | 魔法型宠物 |
| 治疗者 | 辅助治疗，高精神 | 辅助型宠物 |

#### 第四步：选择初始宠物
- 根据职业推荐宠物（高亮显示）
- 支持玩家选择其他宠物
- 显示宠物属性和技能预览

**初始宠物推荐：**

| 职业 | 推荐宠物 | 宠物类型 | 元素属性 |
|------|----------|----------|----------|
| 战士 | 铁甲龟 | 防御型 | 地系 |
| 游侠 | 疾风鹰 | 攻击型 | 风系 |
| 法师 | 火焰狐 | 魔法型 | 火系 |
| 治疗者 | 治愈鹿 | 辅助型 | 木系 |

#### 第五步：确认创建
- 显示角色信息汇总
- 确认后保存到云端
- 进入新手教程

**页面元素：**
- 角色名输入框
- 性别选择按钮
- 职业选择卡片
- 宠物选择列表
- 确认按钮

**数据存储：**
```javascript
// 玩家数据结构
{
  _id: 'player_xxx',
  openid: '微信openid',
  角色名: '玩家名字',
  性别: '男/女',
  职业: '战士/游侠/法师/治疗者',
  初始宠物: '宠物ID',
  等级: 1,
  经验: 0,
  金币: 0,
  感染度: 0,
  创建时间: '2026-07-14',
  最后登录: '2026-07-14'
}
```

### 流程4：新手教程（完整版）

**功能：**
- 教会玩家基本操作
- 通过剧情引导学习
- 休闲难度，不卡进度

**教程场景：**

#### 场景1：醒来 → 学习"移动"操作
```
你从昏迷中醒来，发现自己躺在一堆废墟中。
周围是破败的建筑和生锈的车辆。

【系统提示】点击下方地点，选择要探索的方向。

[选择]
- 查看周围环境
- 寻找有用物品
- 向前走
```

**教学内容：**
- 如何选择地点
- 如何推进剧情

#### 场景2：遇到老者 → 学习"对话"操作
```
一位衣衫褴褛的老者向你走来。
"年轻人，你醒了？你已经昏迷了三天。
这里是废墟城市，2100年的世界。"

【系统提示】选择对话选项，与NPC交互。

[选择]
- 询问身世
- 询问世界现状
- 表示感谢
```

**教学内容：**
- 如何与NPC对话
- 对话选项的影响

#### 场景3：探索废墟 → 学习"探索"操作
```
你决定探索周围的废墟。
在一个破旧的商店里，你发现了一些有用的物品。

【系统提示】搜索物品，获得道具。

[选择]
- 搜索货架
- 检查柜台
- 查看后门
```

**教学内容：**
- 如何搜索物品
- 道具获取方式

#### 场景4：遭遇敌人 → 学习"战斗"操作
```
突然，一群变异鼠向你们扑来！
老者大喊："小心！这些变异鼠很危险！"

【系统提示】进入战斗，选择技能攻击敌人。

[战斗界面]
- 普通攻击
- 使用技能
- 使用道具
- 逃跑
```

**教学内容：**
- 如何进行战斗
- 技能和道具使用

#### 场景5：获得宠物 → 学习"宠物"操作
```
战斗结束后，你发现一只受伤的小动物。
它看起来很虚弱，但眼中透露出灵性。

你决定帮助它，它成为了你的伙伴。

【系统提示】查看宠物信息，喂食宠物。

[选择]
- 查看宠物属性
- 喂食宠物
- 让宠物休息
```

**教学内容：**
- 如何查看宠物信息
- 如何喂食和照顾宠物

---

### 流程5：进入主界面

**功能：**
- 显示游戏主界面
- 解锁完整功能
- 开始正式游戏

**主界面元素：**
- 角色信息栏（等级、血量、经验）
- 宠物信息栏（宠物头像、状态）
- 功能按钮（背包、任务、商城、设置）
- 地图导航（当前位置、可探索区域）
- 感染度显示

```javascript

  角色名: '玩家名字',
  性别: '男/女',
  职业: '战士/游侠/法师/治疗者',
  初始宠物: '宠物ID',
  等级: 1,
  经验: 0,
  金币: 0,
  感染度: 0,
  创建时间: '2026-07-14 14:30:00',
  最后登录: '2026-07-14 14:30:00',
  游戏进度: {
    当前章节: 1,
    当前区域: '废墟城市',

    已完成任务: []

    道具: [],
    装备: [],
    材料: []
```

```javascript
  初始宠物: 'iron_turtle'
}
```

**读取角色：**
```javascript
// 云函数：getPlayer
// 自动根据openid查询
```

**更新角色：**
```javascript
// 云函数：updatePlayer
{
```

## 🎨 UI设计规范

### 页面切换动画
- Logo → 前言：淡入淡出
- 前言 → 角色创建：向左滑动
- 角色创建 → 新手教程：淡入淡出
- 新手教程场景切换：文字渐显

### 颜色方案
- 背景色：深灰色（#1a1a1a）
- 文字色：浅灰色（#e0e0e0）
- 强调色：废土橙（#d4a574）
- 按钮色：深棕色（#8b4513）

### 字体规范
- 标题：24px，加粗
- 正文：16px，常规
- 提示：14px，斜体
