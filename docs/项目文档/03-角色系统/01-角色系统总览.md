# 角色系统总览

## 系统概述

角色系统是"末日废土"的核心系统之一，定义了玩家角色的属性、成长、职业和技能。本系统采用微信小程序触摸屏交互，通过点击选择进行角色培养。

## 角色属性

### 基础属性

| 属性 | 说明 | 初始值 | 成长方式 |
|------|------|--------|----------|
| **生命值（HP）** | 角色生存状态 | 100 | 升级、装备、宠物加成 |
| **魔法值（MP）** | 使用技能消耗 | 50 | 升级、装备、宠物加成 |
| **攻击力（ATK）** | 物理伤害能力 | 10 | 升级、武器、宠物加成 |
| **防御力（DEF）** | 物理防御能力 | 5 | 升级、防具、宠物加成 |
| **速度（SPD）** | 行动顺序 | 10 | 升级、装备、宠物加成 |
| **暴击率（CRIT）** | 暴击概率 | 5% | 升级、装备、宠物加成 |
| **暴击伤害（CRIT DMG）** | 暴击伤害倍率 | 150% | 装备、宠物加成 |

## 角色职业

### 职业类型

| 职业 | 说明 | 优势 | 劣势 |
|------|------|------|------|
| **战士** | 近战物理输出 | 高HP、高ATK | 低SPD |
| **游侠** | 远程物理输出 | 高SPD、高CRIT | 低DEF |
| **法师** | 远程元素输出 | 高元素伤害 | 低HP |
| **治疗者** | 辅助治疗 | 高回复能力 | 低ATK |

### 职业选择

- 游戏开始时选择职业
- 职业影响初始属性和技能
- 后期可通过转职系统改变职业

## 微信小程序交互设计原则

### 1. 触摸屏交互

- **所有操作通过点击完成**，不要求用户输入
- **使用滚动列表**，玩家可以上下滑动查看内容
- **使用卡片式设计**，每个选项/属性都是一个可点击的卡片
- **清晰的视觉反馈**，点击后立即响应

### 2. 界面布局原则

```
┌─────────────────────────────────┐
│  ← 返回        角色属性         │
├─────────────────────────────────┤
│  角色信息卡片（可点击查看详情）  │
├─────────────────────────────────┤
│  属性列表（可滚动）             │
│  ┌─────────────────────────┐   │
│  │ 属性卡片                │   │
│  │ • 显示属性名称和值      │   │
│  │ • 点击查看成长详情      │   │
│  │ • 箭头表示增减          │   │
│  └─────────────────────────┘   │
│  ┌─────────────────────────┐   │
│  │ 下一个属性卡片          │   │
│  └─────────────────────────┘   │
└─────────────────────────────────┘
```

### 3. 信息层级

| 层级 | 内容 | 交互方式 |
|------|------|----------|
| **一级** | 角色核心信息 | 顶部固定显示 |
| **二级** | 详细属性列表 | 可滚动列表 |
| **三级** | 属性详情/成长 | 点击展开 |
| **四级** | 装备/技能详情 | 二级弹窗 |

### 4. 操作按钮

| 按钮 | 位置 | 功能 |
|------|------|------|
| **返回** | 左上角 | 返回上一级 |
| **升级** | 属性旁 | 升级属性（如有可用点数） |
| **装备** | 装备槽 | 打开装备选择界面 |
| **技能** | 技能槽 | 打开技能选择界面 |
