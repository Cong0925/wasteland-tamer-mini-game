# 属性成长表

## 属性成长规则

### 基础成长公式

```
当前属性 = 基础属性 + (等级-1) × 成长值 + 装备加成 + 宠物加成
```

### 成长值说明

| 属性 | 基础值 | 成长值 | 说明 |
|------|--------|--------|------|
| HP | 100 | +15/级 | 生命值成长 |
| ATK | 10 | +2/级 | 攻击力成长 |
| DEF | 5 | +1/级 | 防御力成长 |
| SPD | 10 | +1/级 | 速度成长 |
| CRIT | 5% | +0.5%/级 | 暴击率成长 |
| CRIT DMG | 150% | +2%/级 | 暴击伤害成长 |

## 元素属性成长

### 元素属性获取

| 方式 | 元素属性值 | 说明 |
|------|------------|------|
| **升级** | +2/5级 | 每5级获得2点元素属性（100级时通过升级获得40点） |
| **装备** | +5-50 | 根据装备品质 |
| **宠物** | +10-100 | 根据宠物品质 |
| **技能** | +5-30 | 根据技能等级 |

**元素属性构成示例**（100级玩家）：
- 升级获得：40点（20%）
- 装备获得：60点（30%）
- 宠物获得：80点（40%）
- 技能获得：20点（10%）
- **总计**：200点（达到上限）
