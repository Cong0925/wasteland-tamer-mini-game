## 🏠 中区域详细设计

### 1. 前哨站（安全区）

**场景描述**

```
═══════════════════════════════════════════════════
  🏠 前哨站 - 指挥中心
═══════════════════════════════════════════════════

  你站在前哨站的指挥中心。这里是净化者的一个小型据点，
  墙上挂满了地图和情报，几个士兵正在忙碌地工作。

  指挥官是一位中年女性，她看到你进来，点头示意。
  "欢迎回来，探索者。外面的情况怎么样？"

  这里是安全的，没有变异生物的威胁。

───────────────────────────────────────────────────
  你可以：

  1. 与指挥官对话（接任务、了解剧情）
  2. 前往军需商店（购买中级装备）
  3. 前往药品商店（购买高级药品）
  4. 前往医疗站（治疗、恢复状态）
  5. 前往训练营（学习技能）
  6. 前往城市废墟（21-30级探索）
  7. 前往下水道（25-35级探索）
  8. 前往森林废墟（35-45级探索）
  9. 使用传送系统（快速前往已探索区域）
  10. 查看角色信息
  11. 休息（完全恢复HP/MP）

───────────────────────────────────────────────────
  请输入选项编号：
```

**NPC对话示例**

```
═══════════════════════════════════════════════════
  💬 与指挥官对话
═══════════════════════════════════════════════════

  指挥官看着你，眼神中带着一丝忧虑。

  "城市废墟的情况比我们想象的要严重。我们的侦察兵
  发现那里有大量变异生物聚集，而且...有些不对劲。"

  她压低声音："我们怀疑有人在背后操控这一切。"

───────────────────────────────────────────────────
  你可以：

  1. "是谁在操控？"（询问详情）
  2. "我能帮忙吗？"（接受任务）
  3. "我需要准备一下"（推迟）
  4. "告辞"（结束对话）

───────────────────────────────────────────────────
  请输入选项编号：

```
═══════════════════════════════════════════════════

  2. 前往住宅区（较安全，可能有变异鹿）
  3. 前往市中心（极危险，可能有精英怪）
  4. 搜索街道（可能发现物品）
  5. 返回入口
  6. 查看地图
