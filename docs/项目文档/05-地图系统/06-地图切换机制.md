## ⭐ 快速传送系统（核心功能）

### 设计原则

| 原则 | 说明 |
|------|------|
| **便捷性** | 去过的地方都能传送 |
| **节省时间** | 避免重复跑图 |
| **平衡性** | 传送需要消耗少量资源 |
| **易用性** | 在任何安全区都能使用 |

### 传送解锁条件

| 条件 | 说明 |
|------|------|
| **已探索** | 必须去过该区域（进入过即可） |
| **安全区域** | 只能在安全区使用传送功能 |
| **传送费用** | 消耗少量货币（50-200结晶） |

|------|----------|------|
| 第一幕 | 50结晶 | 新手区域，费用低 |

### 传送限制

| 限制 | 说明 |
|------|------|
| **安全区域** | 只能在安全区使用传送功能 |
| **已探索** | 必须去过该区域才能传送 |
| **等级限制** | 部分区域需要达到特定等级 |
| **任务限制** | 部分区域需要完成特定任务 |
| **货币限制** | 传送需要消耗货币 |
| **战斗中** | 战斗中无法使用传送 |

### 传送快捷键

在任何安全区，都可以通过以下方式打开传送系统：

| 方式 | 操作 | 说明 |
|------|------|------|
| 菜单选项 | 选择"使用传送系统" | 标准方式 |
| 快捷指令 | 输入"传送"或"t" | 快捷方式 |
| NPC对话 | 与传送师对话 | NPC方式 |

| 类型 | 平均时间 | 说明 |
|------|----------|------|
| 区域内切换 | 即时 | 选项选择 |
| 安全区切换 | 即时 | 选项选择 |
| 幕与幕切换 | 即时 | 剧情触发 |
| 传送门切换 | 即时 | 选项确认 |

## 🔧 技术实现

### 切换流程

```
玩家选择切换选项
    │
    ▼
检查切换条件
    │
    ├── 条件满足 ──→ 执行切换
    │                   │
    │                   ▼
    │               显示切换描述
    │                   │
    │                   ▼
    │               加载目标区域
    │                   │
    │                   ▼
    │               显示新区域
    │                   │
    │                   ▼
    │               玩家可操作
    │
    └── 条件不满足 ──→ 显示限制描述
                       │
                       ▼
                   返回原区域
```

### 数据存储

| 数据 | 存储位置 | 说明 |
|------|----------|------|
| 已解锁区域 | 本地存储 | 记录已探索区域 |
| 传送点位置 | 本地存储 | 记录可用传送点 |
| 切换次数 | 服务器存储 | 统计数据 |
| 切换历史 | 本地存储 | 最近10次切换记录 |
