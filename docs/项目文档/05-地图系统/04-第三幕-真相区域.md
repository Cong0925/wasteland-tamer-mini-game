## 🏠 中区域详细设计

### 1. 曙光城（安全区）

**场景描述**

```
═══════════════════════════════════════════════════
  🏠 曙光城 - 净化者总部
═══════════════════════════════════════════════════

  你站在曙光城的净化者总部。这里是净化者的最高指挥部，
  墙上挂满了地图和情报，几个高级军官正在忙碌地工作。

  林清月——净化者的领袖——站在指挥台前，她看到你进来，
  点头示意。

  "欢迎回来，探索者。外面的情况怎么样？"

  这里是安全的，没有变异生物的威胁。

───────────────────────────────────────────────────
  你可以：

  1. 与林清月对话（接任务、了解剧情）
  2. 与赵铁军对话（战斗任务）
  3. 与陈博士对话（科技任务、净化）
  4. 前往净化者商店（购买净化装备）
  5. 前往科技商店（购买科技道具）
  6. 前往医疗中心（治疗、恢复状态）
  7. 前往训练场（学习顶级技能）
  8. 前往核电站废墟（51-65级探索）
  9. 前往秘密实验室（65-75级探索）
  10. 前往山脉区域（75-80级探索）
  11. 使用传送系统（快速前往已探索区域）
  12. 查看角色信息
  13. 休息（完全恢复HP/MP）

───────────────────────────────────────────────────
  请输入选项编号：
```

**NPC对话示例**

```

  林清月看着你，眼神中带着一丝忧虑。

───────────────────────────────────────────────────
  你可以：

  1. "混沌博士是谁？"（询问详情）
  2. "我能帮忙吗？"（接受任务）
  3. "我需要准备一下"（推迟）
  4. "告辞"（结束对话）
```
