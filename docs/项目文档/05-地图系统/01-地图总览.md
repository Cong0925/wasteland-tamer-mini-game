## 🎮 微信小程序交互设计原则

### 设备特性

| 特性 | 说明 |
|------|------|
| **触摸屏** | 用户通过触摸操作 |
| **竖屏显示** | 手机竖屏使用 |
| **点击选择** | 选项通过点击选择，无需输入 |
| **滚动列表** | 长列表支持滚动 |
| **简洁界面** | 避免复杂操作 |

### 地图呈现方式

| 元素 | 呈现方式 | 交互方式 |
|------|----------|----------|
| **场景描述** | 文字卡片 | 自动显示，可滚动 |
| **可选行动** | 可点击按钮列表 | 点击选择 |
| **地图切换** | 区域选择卡片 | 点击选择 |
| **战斗触发** | 系统提示 | 自动触发 |
| **NPC互动** | 对话气泡 + 选项 | 点击选择 |
