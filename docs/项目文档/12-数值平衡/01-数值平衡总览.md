# 数值平衡总览

## 系统概述

数值平衡系统是"末日废土"的核心框架，定义了游戏的整体数值结构、经济系统、成长曲线等。合理的数值设计能确保游戏的可玩性和公平性。

#### 属性成长公式

```
当前属性 = (基础属性 + (等级-1) × 成长值) × 职业修正 + 装备加成 + 宠物加成
```

**说明**：所有职业共享同一套基础成长表，通过职业修正百分比区分职业特色。

| 属性 | 基础值 | 成长值/级 | 说明 |
|------|--------|-----------|------|
| HP | 100 | +15 | 生命值 |
| MP | 50 | +5 | 魔法值 |
| ATK | 10 | +2 | 攻击力 |
| DEF | 5 | +1 | 防御力 |
| SPD | 10 | +1 | 速度 |
| CRIT | 5% | +0.5% | 暴击率 |
| CRIT DMG | 150% | +2% | 暴击伤害 |

#### 职业修正示例

| 职业 | HP修正 | ATK修正 | DEF修正 | SPD修正 |
|------|--------|---------|---------|---------|
| 战士 | +20% | +10% | +10% | -5% |
| 游侠 | -10% | +10% | -10% | +20% |
| 法师 | -20% | 0% | -10% | +10% |
| 治疗者 | +10% | -20% | +10% | 0% |

**示例计算**：
- 战士1级HP：(100 + 0 × 15) × 1.2 = 120
- 治疗者1级HP：(100 + 0 × 15) × 0.9 = 90

| **混沌碎片** | 混沌实验室掉落 | 购买混沌商品 | 稀有 |

### 经济循环

```
玩家获取货币
    ↓
购买装备/道具
    ↓
提升战斗力
    ↓
击败更强敌人
    ↓
获取更多货币
    ↓
购买更高级装备
    ↓
...循环...
```

## 战斗数值

### 伤害公式

```
基础伤害 = ATK × 技能倍率 - DEF × 0.5
元素伤害 = 元素属性 × 技能倍率
最终伤害 = 基础伤害 + 元素伤害
暴击伤害 = 最终伤害 × 暴击伤害倍率
```

### 治疗公式

```
基础治疗 = ATK × 治疗倍率
最终治疗 = 基础治疗 × (1 + 治疗加成)
```

### 护盾公式

```
护盾值 = ATK × 护盾倍率
护盾吸收 = min(护盾值, 受到伤害)
```

## 数值平衡原则

### 1. 成长曲线

- **前期**：快速成长，让玩家有成就感
- **中期**：平稳成长，让玩家有挑战感
- **后期**：缓慢成长，让玩家有追求感

### 2. 难度曲线

- **新手区域**：简单，让玩家熟悉游戏
- **中级区域**：中等，让玩家有挑战
- **高级区域**：困难，让玩家有成就感
- **终局区域**：极难，让玩家有追求

### 3. 经济平衡

- **收入**：通过战斗和任务获取
- **支出**：购买装备和道具
- **平衡**：确保玩家不会太穷或太富

### 4. 掉落平衡

- **普通敌人**：基础物品，满足日常需求
- **精英敌人**：稀有物品，满足进阶需求
- **BOSS**：史诗/传说物品，满足终极需求
