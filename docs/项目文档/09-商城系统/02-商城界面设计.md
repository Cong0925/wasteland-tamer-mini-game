# 商城界面设计

> *"界面设计，决定交易体验。"*

---

## 📊 设计统计

| 项目 | 数量 |
|------|------|
| **界面类型** | 6种 |
| **交互方式** | 触摸屏点击 |
| **布局方式** | 竖屏滚动 |
| **按钮数量** | 4-6个 |

---

## 🎮 界面布局原则

### 布局结构

```
┌─────────────────────────────────┐
│           顶部导航栏            │
│    返回 ←  商店名称  → 菜单    │
├─────────────────────────────────┤
│                                 │
│         商店信息区域            │
│   （商店描述、货币信息）        │
│                                 │
├─────────────────────────────────┤
│                                 │
│         商品分类区域            │
│   （分类标签，可点击切换）      │
│                                 │
├─────────────────────────────────┤
│                                 │
│         商品列表区域            │
│   （商品卡片，可滚动）          │
│                                 │
└─────────────────────────────────┘
```

### 设计原则

| 原则 | 说明 |
|------|------|
| **简洁性** | 避免复杂操作 |
| **直观性** | 信息清晰易懂 |
| **可操作性** | 按钮大小适中 |
| **可读性** | 文字清晰易读 |

## 📋 商店列表界面

### 界面布局

```
┌─────────────────────────────────┐
│  ← 返回        商店列表         │
├─────────────────────────────────┤
│                                 │
│  当前位置: 新手村              │
│  货币: 500结晶                 │
│                                 │
├─────────────────────────────────┤
│  附近商店（可滚动）             │
├─────────────────────────────────┤
│                                 │
│  ┌─────────────────────────┐   │
│  │ 🏪 新手村商店           │   │
│  │    普通商店              │   │
│  │    商品: 15种            │   │
│  │    距离: 50米            │   │
│  └─────────────────────────┘   │
│  ┌─────────────────────────┐   │
│  │ ⚔️ 新手村武器店         │   │
│  │    武器店                │   │
│  │    商品: 8种             │   │
│  │    距离: 80米            │   │
│  └─────────────────────────┘   │
│  ┌─────────────────────────┐   │
│  │ 🛡️ 新手村防具店         │   │
│  │    防具店                │   │
│  │    商品: 8种             │   │
│  │    距离: 100米           │   │
│  └─────────────────────────┘   │
│  ┌─────────────────────────┐   │
│  │ 🕵️ 黑市商人             │   │
│  │    黑市（隐藏）          │   │
│  │    商品: 5种             │   │
│  │    距离: 200米           │   │
│  └─────────────────────────┘   │
│                                 │
└─────────────────────────────────┘
```

### 交互流程

```
打开商店列表
    │
    ▼
显示附近商店
    │
    ▼
点击商店
    │
    ├── 普通商店 → 进入普通商店
    ├── 武器店 → 进入武器店
    ├── 防具店 → 进入防具店
    ├── 黑市 → 进入黑市（需要解锁）
    └── 声望商店 → 进入声望商店（需要声望）
    │
    ▼
显示商店界面
```
