# 交互规范设计

## 触摸交互规范

### 1. 按钮点击

| 规范 | 数值 | 说明 |
|------|------|------|
| **最小点击区域** | 44px × 44px | 微信小程序推荐最小尺寸 |
| **按钮间距** | ≥8px | 防止误触 |
| **点击反馈** | 100ms内 | 立即响应 |
| **点击效果** | 背景色变深 | 视觉反馈 |

#### 按钮状态

| 状态 | 样式 | 说明 |
|------|------|------|
| **默认** | 正常颜色 | 可点击 |
| **按下** | 颜色变深10% | 正在点击 |
| **禁用** | 灰色+透明度50% | 不可点击 |
| **加载** | 显示加载动画 | 正在处理 |

### 2. 列表滚动

| 规范 | 数值 | 说明 |
|------|------|------|
| **列表项高度** | 60-80px | 适合手指点击 |
| **滚动速度** | 平滑滚动 | 自然流畅 |
| **回弹效果** | 到顶/底回弹 | 提示边界 |
| **滚动条** | 隐藏 | 不影响视觉 |

### 3. 手势操作

| 手势 | 操作 | 使用场景 |
|------|------|----------|
| **点击** | 选择/确认 | 所有可点击元素 |
| **长按** | 显示详情/菜单 | 道具、宠物等 |
| **左滑** | 显示操作按钮 | 列表项删除/出售 |
| **下拉** | 刷新/显示历史 | 剧情回看 |
| **双指缩放** | 放大/缩小 | 地图界面 |

## 动画规范

### 1. 页面切换动画

| 动画类型 | 时长 | 效果 |
|----------|------|------|
| **push** | 300ms | 新页面从右向左滑入 |
| **pop** | 300ms | 当前页面从左向右滑出 |
| **replace** | 200ms | 淡入淡出 |
| **弹窗** | 200ms | 从底部弹出 |

### 2. 元素动画

| 动画类型 | 时长 | 使用场景 |
|----------|------|----------|

| **数字跳动** | 300ms | HP/经验值变化 |
| **图标弹跳** | 500ms | 获得物品 |

### 3. 战斗动画

| 动画类型 | 时长 | 效果 |
|----------|------|------|
| **攻击** | 300ms | 角色冲向敌人 |
| **技能** | 500ms | 技能特效 |
| **伤害** | 200ms | 数字跳出 |
| **击败** | 500ms | 敌人消失 |
| **捕捉** | 1000ms | 捕捉球动画 |

### 4. 过渡动画

| 动画类型 | 时长 | 使用场景 |
|----------|------|----------|
| **展开** | 200ms | 折叠内容展开 |
| **收起** | 200ms | 内容收起 |
| **旋转** | 300ms | 刷新按钮 |
| **闪烁** | 500ms | 提示信息 |

## 反馈规范

### 1. 触觉反馈

| 反馈类型 | 场景 | 强度 |
|----------|------|------|
| **轻震** | 按钮点击 | 轻微 |
| **中震** | 重要操作 | 中等 |
| **重震** | 危险操作 | 较强 |
| **双震** | 成功/失败 | 两次轻震 |

### 2. 音效反馈

| 反馈类型 | 场景 | 音效 |
|----------|------|------|
| **点击** | 按钮点击 | 轻微点击声 |
| **确认** | 确认操作 | 清脆提示音 |
| **成功** | 操作成功 | 成功音效 |
| **失败** | 操作失败 | 失败音效 |
| **战斗** | 战斗相关 | 战斗音效 |

### 3. 视觉反馈

| 反馈类型 | 场景 | 效果 |
|----------|------|------|
| **高亮** | 选中元素 | 背景色变深 |
| **闪烁** | 提示信息 | 文字闪烁 |
| **震动** | 错误操作 | 元素左右震动 |
| **弹跳** | 获得物品 | 图标弹跳 |

## 加载状态规范

### 1. 页面加载

| **处理失败** | 错误提示 | 操作失败 |

### 3. 加载动画

| 动画类型 | 使用场景 | 说明 |
|----------|----------|------|
| **旋转圆圈** | 页面加载 | 通用加载 |
| **进度条** | 明确进度 | 下载/上传 |
| **骨架屏** | 页面预加载 | 提升体验 |
| **文字动画** | 等待时间 | 趣味提示 |

## 无障碍规范

### 1. 字体大小

| 级别 | 字号 | 使用场景 |
|------|------|----------|
| **小** | 12px | 次要信息 |
| **中** | 14px | 正文（默认） |
| **大** | 16px | 适老化 |
| **特大** | 18px | 适老化 |

### 2. 颜色对比度

| 元素 | 对比度 | 说明 |
|------|--------|------|
| **文字** | ≥4.5:1 | 正常视力 |
| **图标** | ≥3:1 | 色盲友好 |
| **按钮** | ≥4.5:1 | 清晰可辨 |

### 3. 屏幕阅读器

| 规范 | 说明 |
|------|------|
| **aria-label** | 为图标按钮添加描述 |
| **role** | 使用正确的语义角色 |
| **tabindex** | 合理的焦点顺序 |
