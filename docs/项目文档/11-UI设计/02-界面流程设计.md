# 界面流程设计

## 整体流程

### 游戏启动流程

```
启动小程序
    ↓
加载界面（显示游戏名称、进度条）
    ↓
主菜单界面
    ├── [开始游戏] → 新手引导 → 游戏主界面
    ├── [继续游戏] → 读取存档 → 游戏主界面
    └── [设置] → 设置界面
```

### 游戏主界面流程

```
游戏主界面（场景页面）
    │
    ├── [探索] → 探索选项 → 事件触发
    │                      ├── 遇敌 → 战斗界面
    │                      ├── 剧情 → 剧情界面
    │                      └── 宝箱 → 获得物品
    │
    ├── [地图] → 地图界面 → 区域选择 → 传送确认
    │
    ├── [战斗] → 战斗界面 → 战斗结算
    │
    └── [宠物] → 宠物界面 → 宠物管理
```

## 战斗界面流程

### 回合制战斗流程

```
进入战斗
    ↓
战斗开始动画
    ↓
战斗界面
    │
    ├── [攻击] → 选择目标 → 造成伤害
    │
    ├── [技能] → 技能列表 → 选择技能 → 选择目标 → 释放技能
    │
    ├── [道具] → 道具列表 → 选择道具 → 使用道具
    │   └── 快捷商城 → 购买道具
    │
    ├── [宠物] → 宠物列表 → 切换宠物
    │
    └── [逃跑] → 逃跑判定 → 成功/失败
            ↓
    敌方行动 → 造成伤害
            ↓
    回合结束判定
    │
    ├── 胜利 → 战斗结算 → 获得奖励
    ├── 失败 → 失败界面 → 选项
    │           ├── [复活] → 消耗道具
    │           └── [返回] → 回到安全区
    └── 继续 → 回到战斗界面
```

### 捕捉流程

```
进入捕捉模式
    ↓
捕捉界面
    │
    ├── 查看捕捉概率
    │   ├── 敌人HP越低，概率越高
    │   ├── 不同捕捉球，概率不同
    │   └── 元素克制，概率加成
    │
    ├── 选择捕捉球
    │   ├── 标准捕捉球 (30%)
    │   ├── 高级捕捉球 (60%)
    │   └── 稀有捕捉球 (90%)
    │
    └── 使用捕捉球
        ├── 成功 → 捕捉成功动画 → 获得宠物
        └── 失败 → 捕捉失败动画 → 敌人行动
```

## 页面跳转规则

### 跳转方式

| 方式 | 说明 | 使用场景 |
|------|------|----------|
| **push** | 压入新页面 | 进入新功能 |
| **pop** | 返回上一页 | 返回操作 |
| **replace** | 替换当前页面 | 切换Tab |
| **popToRoot** | 返回根页面 | 点击底部Tab |

### 跳转限制

| 规则 | 说明 |
|------|------|
| **战斗中不可跳转** | 战斗中只能使用道具/宠物 |
| **弹窗中不可跳转** | 弹窗关闭前不可操作其他 |
| **加载中不可跳转** | 页面加载完成前不可操作 |
