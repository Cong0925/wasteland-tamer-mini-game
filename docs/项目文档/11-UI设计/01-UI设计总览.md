# UI设计总览

## 设计概述

UI设计是"末日废土"微信小程序的界面和交互设计，采用纯文字选择类RPG形式，适配触摸屏操作，结合怀旧WAP文字游戏风格和现代微信小程序体验。

## 设计原则

### 1. 怀旧风格 + 现代体验

| 方面 | 怀旧元素 | 现代优化 |
|------|----------|----------|
| **视觉** | 低饱和配色、简约文字 | 圆角卡片、平滑动画 |
| **交互** | 文字链接选择 | 大尺寸触摸按钮 |
| **音效** | 8-bit风格音效 | 高品质音效 |
| **存档** | 手动存档 | 自动存档+云同步 |

### 2. 触摸屏优先

| 原则 | 说明 |
|------|------|
| **大按钮** | 所有可点击区域≥44px |
| **足够间距** | 按钮间距≥16px |
| **清晰反馈** | 点击后立即响应 |
| **防误触** | 重要操作需要确认 |

### 3. 信息层级清晰

| 层级 | 内容 | 位置 |
|------|------|------|
| **一级** | 核心信息（HP、货币） | 顶部固定 |
| **二级** | 主要操作（选项按钮） | 中间区域 |
| **三级** | 次要信息（详细数据） | 可滚动列表 |
| **四级** | 系统功能（设置、图鉴） | 底部导航/二级页面 |

## 底部导航设计

### 导航结构

采用**5栏底部导航**，符合微信小程序规范：

| 位置 | 图标 | 名称 | 核心功能 |
|------|------|------|----------|
| 1 | 🗺️ | 场景 | 主探索、遇敌、捕捉、战斗、地图 |
| 2 | 🐾 | 宠物 | 宠物列表、培养、进化、仓库 |
| 3 | 📖 | 剧情 | 主线剧情、支线、剧情回顾 |
| 4 | 🏪 | 商城 | 道具、礼包、捕捉球、付费内容 |
| 5 | 👤 | 我的 | 角色、背包、图鉴、设置、竞技场 |

### 导航布局

```
┌─────────────────────────────────┐
│                                 │
│          内容区域               │
│                                 │
├─────────────────────────────────┤
│ [🗺️场景] [🐾宠物] [📖剧情]    │
│ [🏪商城] [👤我的]              │
└─────────────────────────────────┘
```

### 导航状态

| 状态 | 说明 | 样式 |
|------|------|------|
| **默认** | 未选中 | 灰色图标+文字 |
| **选中** | 当前页面 | 主题色图标+文字 |
| **禁用** | 不可用 | 浅灰色+点击无响应 |

## 视觉规范

### 颜色规范

| 颜色 | 用途 | 色值 |
|------|------|------|
| **主色** | 主题色、选中状态 | #2A5CAA |
| **辅色** | 次要元素、边框 | #6B8CC7 |
| **背景色** | 页面背景 | #F5F5F5 |
| **卡片色** | 卡片背景 | #FFFFFF |
| **文字色** | 主要文字 | #333333 |
| **次要文字** | 次要信息 | #999999 |
| **成功色** | 成功、恢复 | #52C41A |
| **警告色** | 警告、提示 | #FAAD14 |
| **危险色** | 危险、伤害 | #FF4D4F |

### 字体规范

| 类型 | 字号 | 行高 | 用途 |
|------|------|------|------|
| **标题** | 18px | 24px | 页面标题 |
| **副标题** | 16px | 22px | 卡片标题 |
| **正文** | 14px | 20px | 主要内容 |
| **次要** | 12px | 16px | 次要信息 |
| **提示** | 10px | 14px | 提示文字 |

### 间距规范

| 类型 | 尺寸 | 用途 |
|------|------|------|
| **页面边距** | 16px | 页面左右边距 |
| **卡片间距** | 12px | 卡片之间间距 |
| **内容间距** | 8px | 内容元素间距 |
| **按钮间距** | 8px | 按钮之间间距 |

## 组件规范

### 1. 卡片组件

```
┌─────────────────────────────────┐
│  卡片内容                       │
│  • 圆角: 8px                    │
│  • 阴影: 0 2px 8px rgba(0,0,0,0.1)│
│  • 内边距: 12px                 │
└─────────────────────────────────┘
```

### 2. 按钮组件

| 类型 | 样式 | 用途 |
|------|------|------|
| **主按钮** | 蓝色背景+白色文字 | 主要操作 |
| **次按钮** | 白色背景+蓝色边框 | 次要操作 |
| **危险按钮** | 红色背景+白色文字 | 危险操作 |
| **禁用按钮** | 灰色背景+灰色文字 | 不可用状态 |
