## 🎯 道具分类

### 1. 消耗品

| 类型 | 说明 | 使用方式 |
|------|------|----------|
| **药品** | 恢复HP/MP | 战斗中/战斗外 |
| **解毒剂** | 解除负面状态 | 战斗中/战斗外 |
| **增益药剂** | 临时提升属性 | 战斗中/战斗外 |
| **捕捉球** | 捕捉宠物 | 战斗中 |

### 2. 材料

| 类型 | 说明 | 用途 |
|------|------|------|
| **制作材料** | 用于制作装备 | 铁匠制作 |
| **强化材料** | 用于强化装备 | 铁匠强化 |
| **进化材料** | 用于宠物进化 | 宠物系统 |
| **任务材料** | 用于完成任务 | 任务系统 |

### 3. 装备

| 类型 | 说明 | 装备位置 |
|------|------|----------|
| **武器** | 提升攻击力 | 武器栏 |
| **防具** | 提升防御力 | 防具栏 |
| **饰品** | 提升特殊属性 | 饰品栏 |

### 4. 任务物品

| 类型 | 说明 | 获取方式 |
|------|------|----------|
| **剧情物品** | 推进剧情 | 任务奖励 |
| **线索物品** | 提供信息 | 探索获得 |
| **钥匙物品** | 解锁区域 | 任务奖励 |

### 5. 特殊物品

| 类型 | 说明 | 用途 |
|------|------|------|
| **传送道具** | 快速传送 | 使用后传送 |
| **地图道具** | 显示地图 | 使用后显示 |
| **宠物道具** | 宠物相关 | 宠物系统 |

### 6. 货币

**货币体系说明**：
- **世界观设定**：三阶货币体系（碎片→结晶→核心）
- **游戏实际使用**：统一使用"结晶"作为主要货币单位
- **转换关系**：10碎片=1结晶，100结晶=1核心（背景设定，游戏中不实际使用）

| 类型 | 说明 | 用途 | 获取方式 |
|------|------|------|----------|
| **结晶** | 基础货币 | 购买物品、交易 | 击败怪物、完成任务、出售物品 |
| **净化者徽章** | 声望货币 | 净化者商店 | 净化者声望任务 |
| **混沌碎片** | 特殊货币 | 混沌商店 | 混沌地带探索 |

### 捕捉球类

**说明**：捕捉球捕捉率计算公式为：基础捕捉率 × (1 + 捕捉球加成)。基础捕捉率由宠物稀有度决定。

| 宠物稀有度 | 基础捕捉率 | 说明 |
|-----------|-----------|------|
| ★ 普通 | 50% | 容易捕捉 |
| ★★ 优秀 | 30% | 较难捕捉 |
| ★★★ 稀有 | 15% | 很难捕捉 |
| ★★★★ 史诗 | 5% | 极难捕捉 |
| ★★★★★ 传说 | 1% | 几乎不可能 |

| 道具ID | 道具名称 | 捕捉率加成 | 价格 | 获取方式 |
|--------|----------|-----------|------|----------|
| C21 | 标准捕捉球 | +0% | 10结晶 | 商店购买 |
| C22 | 强化捕捉球 | +20% | 30结晶 | 商店购买 |
| C23 | 高级捕捉球 | +40% | 60结晶 | 商店购买、任务奖励 |
| C24 | 大师捕捉球 | +60% | 120结晶 | 商店购买、稀有掉落 |
| C25 | 传说捕捉球 | +80% | 300结晶 | 任务奖励、极稀有掉落 |

**捕捉示例**：
- 用标准捕捉球捕捉★普通宠物：50% × (1+0%) = 50%
- 用传说捕捉球捕捉★★优秀宠物：30% × (1+80%) = 54%
- 用传说捕捉球捕捉★★★稀有宠物：15% × (1+80%) = 27%

### 装备强化系统

**说明**：装备可以通过强化提升属性，强化需要消耗强化石和结晶。

| 强化等级 | 属性提升 | 所需材料 | 成功率 |
|----------|----------|----------|--------|
| +1 | +10% | 强化石x1 + 10结晶 | 100% |
| +2 | +20% | 强化石x2 + 20结晶 | 95% |
| +3 | +30% | 强化石x3 + 30结晶 | 90% |
| +4 | +40% | 高级强化石x1 + 50结晶 | 85% |
| +5 | +50% | 高级强化石x2 + 80结晶 | 80% |
| +6 | +60% | 高级强化石x3 + 120结晶 | 75% |
| +7 | +70% | 顶级强化石x1 + 200结晶 | 70% |
| +8 | +80% | 顶级强化石x2 + 300结晶 | 60% |
| +9 | +90% | 顶级强化石x3 + 500结晶 | 50% |
| +10 | +100% | 顶级强化石x5 + 800结晶 | 30% |

**强化失败惩罚**：
- +1至+3：失败无惩罚
- +4至+6：失败降低1级
- +7至+10：失败降低2级，有概率损坏装备

**保护措施**：
- 保护符：强化失败时保护装备不降级
- 幸运符：提高强化成功率
