## 🎯 使用方式分类

### 1. 战斗中使用

| 道具类型 | 使用效果 | 使用时机 |
|----------|----------|----------|
| 药品 | 恢复HP/MP | 任何回合 |
| 解毒剂 | 解除负面状态 | 任何回合 |
| 增益药剂 | 临时提升属性 | 任何回合 |
| 捕捉球 | 捕捉宠物 | 任何回合 |

### 2. 战斗外使用

| 道具类型 | 使用效果 | 使用场景 |
|----------|----------|----------|
| 药品 | 恢复HP/MP | 安全区、探索中 |
| 解毒剂 | 解除负面状态 | 安全区、探索中 |
| 增益药剂 | 临时提升属性 | 安全区、探索中 |
| 传送道具 | 快速传送 | 安全区 |

### 3. 装备使用

| 道具类型 | 使用效果 | 使用场景 |
|----------|----------|----------|
| 武器 | 提升攻击力 | 任何时候 |
| 防具 | 提升防御力 | 任何时候 |
| 饰品 | 提升特殊属性 | 任何时候 |

### 4. 特殊使用

| 道具类型 | 使用效果 | 使用场景 |
|----------|----------|----------|
| 任务物品 | 推进剧情 | 特定NPC |
| 线索物品 | 提供信息 | 任何时候 |
| 钥匙物品 | 解锁区域 | 特定地点 |

## 📋 使用限制

### 使用场景限制

| 限制类型 | 说明 |
|----------|------|
| **战斗中** | 只有消耗品可以在战斗中使用 |
| **战斗外** | 所有道具都可以在战斗外使用 |
| **安全区** | 传送道具只能在安全区使用 |

### 使用等级限制

| 限制类型 | 说明 |
|----------|------|
| **等级要求** | 装备需要达到特定等级 |
| **物品要求** | 部分道具需要前置物品 |

### 使用次数限制

| 限制类型 | 说明 |
|----------|------|
| **每日次数** | 部分道具有每日使用次数 |
| **总次数** | 消耗品使用后消失 |

### 使用冷却限制

| 限制类型 | 说明 |
|----------|------|
| **战斗冷却** | 部分道具有战斗冷却时间 |
| **全局冷却** | 部分道具有全局冷却时间 |

### 使用数量限制

| 限制类型 | 说明 |
|----------|------|
| **堆叠上限** | 部分道具有堆叠上限 |
| **携带上限** | 部分道具有携带上限 |
