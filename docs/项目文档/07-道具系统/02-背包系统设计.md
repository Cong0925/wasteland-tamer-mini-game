# 背包系统设计

> *"背包是你的移动仓库，合理管理是生存的关键。"*

---

## 📊 系统统计

| 项目 | 数量 |
|------|------|
| **背包类型** | 3种 |
| **初始容量** | 20格 |
| **最大容量** | 100格 |
| **分类数量** | 6类 |

---

## 🎯 背包类型

### 1. 物品背包

| 特性 | 说明 |
|------|------|
| **用途** | 存放消耗品、材料、任务物品 |
| **初始容量** | 20格 |
| **扩展方式** | 购买背包扩展券 |
| **最大容量** | 100格 |

### 2. 装备背包

| 特性 | 说明 |
|------|------|
| **用途** | 存放武器、防具、饰品 |
| **初始容量** | 10格 |
| **扩展方式** | 购买装备栏扩展券 |
| **最大容量** | 50格 |

### 3. 宠物背包

| 特性 | 说明 |
|------|------|
| **用途** | 存放捕捉的宠物 |
| **初始容量** | 6只 |
| **扩展方式** | 购买宠物栏扩展券 |
| **最大容量** | 30只 |

### 交互流程

```
打开背包
    │
    ▼
显示物品列表
    │
    ▼
点击物品
    │
    ├── 消耗品 → 显示使用/丢弃选项
    ├── 材料 → 显示查看/丢弃选项
    ├── 任务物品 → 显示查看选项
    └── 特殊物品 → 显示使用/查看选项
    │
    ▼
选择操作
    │
    ├── 使用 → 执行使用效果
    ├── 查看 → 显示物品详情
    └── 丢弃 → 确认丢弃
    │
    ▼
更新背包
```
