## ⚔️ 详细势力设定

### 1. 净化者（The Purifiers）

| 属性 | 描述 |
|------|------|
| **立场** | 正义 |
| **目标** | 净化被污染的世界，恢复生态 |
| **口号** | "净化大地，重获新生" |
| **根据地** | 高山据点"曙光城" |
| **实力** | 中等偏上，科技水平较高 |

#### 组织结构

```
          净化者领袖
               │
    ┌──────────┼──────────┐
    ↓          ↓          ↓
 作战部      研究部      后勤部
    │          │          │
 战斗小队   实验室     资源采集
 侦察小队   医疗队     食物生产
```

#### 核心人物

| 职位 | 姓名 | 特点 |
|------|------|------|
| **领袖** | 林清月 | 前联合国官员，理想主义者 |
| **作战部长** | 赵铁军 | 前特种兵，沉默寡言 |
| **研究部长** | 陈博士 | 病毒学家，寻找净化方法 |
| **侦察队长** | 待定 | 玩家可能遇到的第一个NPC |

#### 玩家与净化者的关系

- **初始关系**：中立（需要完成任务提升声望）
- **互动方式**：接受任务、购买物资、获取情报
- **声望系统**（统一为5级）：
  - 仇恨(-1000~-500) → 敌对(-500~-100) → 中立(-100~100) → 友好(100~500) → 崇敬(500~1000)
- **奖励**：高级净化道具、特殊装备、剧情线索

### 5. 混沌博士（Doctor Chaos）

> *"那片土地的确可能诞生天才，但大都不是很正常。"*
> *——旧时代人们对环海之国的评价*

| 属性 | 描述 |
|------|------|
| **真实身份** | 环海之国（帝国）基因工程首席科学家 |
| **立场** | 疯狂（表面）/ 悲剧英雄（真实） |
| **动机1** | 净化世界——用混沌力量清除污染（真实目的） |
| **动机2** | 人类进化——通过变异实现"新人类"（表面目的） |
| **口号** | "科学没有边界，变异就是自由" |
| **根据地** | 沉睡的活火山内部"混沌实验室" |
| **实力** | 极其强大，拥有大量变异体军队 |

#### 背景故事

```
旧时代（2040年之前）
    │
    ├── 环海之国（帝国）是科技强国
    │
    ├── 混沌博士是基因工程天才
    │
    ├── 他的研究被政府禁止（认为太危险）
    │
    └── 他怀恨在心，认为政府阻碍了人类进化

核废水事件（2040年）
    │
    ├── 帝国政府决定排放核废水
    │
    ├── 混沌博士发现这是绝佳的实验机会
    │
    ├── 他秘密加强了核废水的变异诱导性
    │
    └── 变异潮比预期来得更快、更猛烈

核战争爆发（2050年）
    │
    ├── 各国因环境变化互相指责
    │
    ├── 核战争加速环境崩溃
    │
    └── 异化现象全面爆发

帝国崩溃（2055年）
    │
    ├── 帝国政府垮台，混沌博士发现帝国的阴谋
    │
    ├── 他意识到自己被利用，开始反思自己的行为
    │
    ├── 他带着研究资料消失
    │
    └── 在活火山内部建立秘密实验室

转变期（2055-2070年）
    │
    ├── 混沌博士发现混沌力量可以"净化"世界
    │
    ├── 但净化的代价是消灭现有生物
    │
    ├── 他认为这是"拯救"，实际上是毁灭
    │
    └── 他开始制造变异体军队，准备执行"净化计划"

游戏开始（2100年）
    │
    ├── 混沌博士已经创造了多个强大变异体
    │
    ├── 他正在制造"终极变异体"
    │
    ├── 他垄断了精纯神秘物质的来源
    │
    └── 玩家最终需要阻止他的"净化计划"
```

#### 混沌博士的真实目的

```
混沌博士的动机演变：

1. 早期（2040年之前）：
   - 目标：证明自己的研究价值
   - 行为：进行危险的基因工程实验
   - 结果：研究被政府禁止

2. 中期（2040-2050年）：
   - 目标：证明变异可以拯救人类
   - 行为：秘密加强核废水的变异诱导性
   - 结果：变异潮爆发，人类文明崩溃

3. 转变期（2055-2070年）：
   - 目标：用混沌力量"净化"世界
   - 行为：研究混沌力量，制造变异体军队
   - 结果：形成自己的势力

4. 游戏开始（2100年）：
   - 目标：执行"净化计划"
   - 行为：垄断混沌力量，准备最终决战
   - 结果：玩家需要阻止他

混沌博士的悲剧：
- 他最初是加害者（秘密加强核废水变异诱导性）
- 核战争后，他发现帝国的阴谋，开始反思
- 他决定用混沌力量"净化"世界，但方法是错误的
- 他认为这是"拯救"，实际上是毁灭
- 最终，他成为了一个悲剧英雄
```

#### 组织结构

```
          混沌博士（唯一核心）
               │
    ┌──────────┼──────────┐
    ↓          ↓          ↓
 变异体军队  实验室    防御系统
    │          │          │
 低级变异体  研究设备   火山防御
 高级变异体  实验品     陷阱机关
 BOSS级      数据库     自毁装置
```

#### 核心人物

| 职位 | 姓名 | 特点 |
|------|------|------|
| **博士本人** | 混沌博士 | 疯狂天才，没有道德底线，坚信自己在"拯救"人类 |
| **助手（可能）** | 待定 | 可能是被控制的变异体，或被洗脑的人类 |
| **守卫BOSS** | 待定 | 守护火山入口的强力变异体 |
| **实验体BOSS** | 待定 | 混沌博士创造的失败/成功品 |

#### 混沌博士的"新人类"计划

```
混沌博士的终极目标：
    │
    ├── 第一步：制造大规模变异（已完成）
    │
    ├── 第二步：筛选"良性变异"个体（进行中）
    │
    ├── 第三步：创造"完美变异体"（进行中）
    │
    ├── 第四步：将"完美变异"应用到人类（计划中）
    │
    └── 第五步：建立"新人类"帝国（终极目标）

他对玩家的态度：
    │
    ├── 初期：密切关注（玩家是07号实验体，他一直在监视）
    │
    ├── 中期：产生兴趣（玩家展现特殊能力，超出预期）
    │
    ├── 后期：想要捕获玩家进行研究（玩家是实验成功的关键）
    │
    └── 最终：与玩家决战（玩家阻止他的"净化计划"）
```

#### 玩家与混沌博士的关系

- **初始关系**：无交集
- **剧情发展**：
  1. 中期发现混沌博士的存在和阴谋
  2. 后期揭露他与核废水事件的关系
  3. 最终对决，从他或他的终极变异体身上提取抗辐射变异物质
- **最终目标**：获取抗辐射变异物质，净化世界

## 🎭 势力冲突

### 主要冲突

| 冲突 | 说明 | 影响 |
|------|------|------|
| **净化者 vs 掠夺者** | 正义与邪恶的永恒斗争 | 玩家可能需要选边站 |
| **军阀内斗** | 各军阀争夺资源和地盘 | 玩家可能被卷入 |
| **所有势力 vs 混沌博士** | 最终的大决战 | 所有势力可能联合 |

### 玩家选择

玩家在游戏中需要做出选择：
- **帮助哪个势力？**：影响剧情走向和结局
- **是否揭露混沌博士？**：影响最终决战的难度
- **选择哪个结局？**：净化、共存、还是毁灭？
