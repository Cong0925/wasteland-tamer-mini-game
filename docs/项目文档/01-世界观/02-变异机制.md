## 🧬 变异起源

### 核废水污染链

```
环海之国核废水排放（2040年）
        ↓
    海洋污染（潜移默化，持续5年）
        ↓
海洋生物大规模变异（第一代变异体，2044年）
        ↓
变异海洋生物获得两栖能力，开始登陆（2045年）
        ↓
沿海城市沦陷，人类意识到危机（2045-2050年）
        ↓
核战争爆发（2050年）→ 环境崩溃，异化加速
        ↓
接触陆地动物/人类
        ↓
        ├──→ 动物感染
        │        ↓
        │   ┌────┴────┐
        │   ↓         ↓
        │ 良性变异  基因崩溃
        │  (30%)    (70%)
        │   ↓         ↓
        │ 可驯服    敌对怪物
        │
        └──→ 人类感染
                 ↓
            不会变异
                 ↓
            逐渐虚弱
                 ↓
            最终死亡
                 ↓
        唯一延缓方法：神秘物质
```

## 👤 人类感染机制

### 感染途径

| 途径 | 说明 | 风险等级 |
|------|------|----------|
| **直接接触** | 被变异生物抓伤/咬伤 | ★★★★★ |
| **污染水源** | 饮用被污染的水 | ★★★★☆ |
| **空气传播** | 在高辐射区域呼吸 | ★★★☆☆ |
| **食物链** | 食用被污染的食物 | ★★☆☆☆ |

### 感染症状

| 阶段 | 时间 | 症状 | 神秘物质效果 |
|------|------|------|--------------|
| **潜伏期** | 1-7天 | 无明显症状 | - |
| **初期** | 1-2周 | 乏力、发热、皮肤出现斑点 | 可完全抑制 |
| **中期** | 2-4周 | 器官开始衰竭、意识模糊 | 可延缓50% |
| **后期** | 1-2月 | 严重衰竭、生命垂危 | 可延缓30% |
| **末期** | 数天内 | 死亡 | 无法逆转 |

### 感染值系统（游戏内）

```
玩家状态栏显示：
┌─────────────────────────────────┐
│  感染度：15%  [███████░░░░░░░]  │
│  神秘物质：125 单位              │
│  预计剩余时间：约30天            │
└─────────────────────────────────┘

规则：
- 感染度达到100%时，游戏结束
- 使用神秘物质可降低感染度
- 不同品质的神秘物质效果不同
```

变异生物体内核心

↓               ↓
普通神秘物质   精纯神秘物质

| **净化材料** | 制作净化道具的关键材料 | 大量 |
| **进化催化** | 宠物进化时可能需要 | 特定数量 |

## 🔄 变异类型

### 1. 良性变异（可驯服）

| 特征 | 说明 |
|------|------|
| **理智保留** | 变异后仍保留原有智能 |
| **能力提升** | 获得超越普通生物的能力 |
| **可控性** | 可以被人类驯服 |
| **进化潜力** | 可以继续进化，变得更强大 |

**可驯服宠物类型**：
- 猫、狗、鼠、鸟、乌龟、金鱼
- 其他良性变异生物

**驯服判定标准**：
| 条件 | 说明 |
|------|------|
| 生物类型 | 必须是"良性变异"个体 |
| 生命值 | 必须低于30% |
| 玩家等级 | 需要一定等级才能驯服高级宠物 |
| 道具需求 | 需要对应的捕捉道具 |

### 2. 基因崩溃（敌对怪物）

| 特征 | 说明 |
|------|------|
| **理智丧失** | 变成只知攻击的怪物 |
| **身体异化** | 外形发生扭曲变化 |
| **攻击性** | 对所有生物充满敌意 |
| **危险性** | 高度危险，必须消灭 |

**基因崩溃特征**：
- 眼睛发红光
- 身体部位异常肿大或扭曲
- 发出非正常声音
- 攻击一切移动物体

## 📊 变异等级体系

### 变异生物强度分级

| 等级 | 名称 | 特征 | 威胁度 | 神秘物质掉落 |
|------|------|------|--------|--------------|
| **I** | 初级变异 | 轻微变异，能力弱 | ★☆☆☆☆ | 1-3 单位 |
| **II** | 中级变异 | 明显变异，能力中等 | ★★☆☆☆ | 5-10 单位 |
| **III** | 高级变异 | 强大变异，能力较强 | ★★★☆☆ | 15-25 单位 |
| **IV** | 精英变异 | 非常强大，有特殊能力 | ★★★★☆ | 30-50 单位 |
| **V** | 灾厄变异 | 极其强大，区域威胁 | ★★★★★ | 100+ 单位 |
| **???** | 终极变异 | 混沌博士的杰作 | ?????? | 抗辐射变异物质 |

### 变异影响因素

1. **污染程度**：接触的核辐射量
2. **生物体质**：原生物的健康状况
3. **接触时间**：被感染的持续时间
4. **随机因素**：运气（决定良性还是崩溃）

## 🐾 宠物变异详解

### 可驯服宠物的变异特征

#### 猫的变异
- **良性特征**：夜视能力增强、敏捷提升、可感知危险
- **基因崩溃**：体型巨大化、攻击性增强、眼睛发红光

#### 狗的变异
- **良性特征**：忠诚度增强、嗅觉敏锐、可发出威慑性低吼
- **基因崩溃**：狂暴化、群体攻击、撕咬能力极强

#### 鼠的变异
- **良性特征**：钻洞能力增强、可感知电子信号、繁殖力提升
- **基因崩溃**：鼠群化、传播疾病、啃咬一切

#### 鸟的变异
- **良性特征**：飞行能力增强、可传递信息、侦察范围扩大
- **基因崩溃**：俯冲攻击、声音干扰、群体骚扰

#### 乌龟的变异
- **良性特征**：防御力极强、寿命延长、可承载重物
- **基因崩溃**：壳硬化、撞击攻击、难以杀死

#### 金鱼的变异
- **良性特征**：可感应其他变异体、水下呼吸、释放治愈能量
- **基因崩溃**：水系攻击、污染水域、召唤同类

## 🔬 混沌博士的实验

### 身份背景

> *"那片土地的确可能诞生天才，但大都不是很正常。"*
> *——旧时代人们对环海之国的评价*

| 属性 | 描述 |
|------|------|
| **真实身份** | 环海之国（帝国）基因工程首席科学家 |
| **真实动机** | 用混沌力量净化世界，消除感染（代价是消灭现有生物） |
| **表面动机** | 实现人类进化，创造完美生物 |
| **根据地** | 沉睡的活火山内部"混沌实验室" |
| **现状** | 继续着疯狂的实验，执行"净化计划" |

### 背景故事

```
早期（2040年之前）：
    ├── 研究基因工程，试图证明变异可以拯救人类
    ├── 研究被帝国政府禁止，怀恨在心
    └── 开始秘密进行实验

中期（2040-2050年）：
    ├── 秘密加强核废水的变异诱导性
    ├── 加速灾难爆发，证明自己的研究价值
    └── 帝国政府垮台后开始反思

转变期（2050-2070年）：
    ├── 发现混沌力量可以净化世界
    ├── 制定"净化计划"，代价是消灭现有生物
    └── 继续实验，寻找净化世界的方法

游戏开始（2100年）：
    ├── 执行"净化计划"
    ├── 创造终极变异体作为武器
    └── 玩家需要阻止或理解他
```

### 实验目的

混沌博士的实验目的分为表面和真实两层：

**表面目的**（向外界宣称）：
1. **控制变异**：让所有变异都变成"良性"
2. **创造完美生物**：融合多种变异的优点
3. **实现"新人类"**：通过变异让人类进化

**真实目的**（只有他自己知道）：
1. **净化世界**：用混沌力量消除所有感染
2. **代价**：消灭现有生物，创造新的生态系统
3. **终极目标**：让世界恢复到没有污染的状态

### 实验手段

- **基因编辑**：强行修改生物基因
- **辐射强化**：利用核辐射加速变异
- **杂交实验**：将不同变异体进行杂交
- **活体实验**：用人类进行实验（极其残忍）

### 实验产物

| 类型 | 说明 | 游戏作用 |
|------|------|----------|
| **失败品** | 基因崩溃的怪物 | 成为普通敌人 |
| **成功品** | 强大的变异体 | 成为BOSS |
| **完美品** | 终极变异体 | 最终BOSS |

### 混沌博士与神秘物质

- 混沌博士发现了神秘物质的真正价值
- 他垄断了精纯神秘物质的来源
- 最终BOSS体内含有"抗辐射变异物质"
- 这是净化世界的关键

## 🎯 玩家与变异的关系

### 玩家能力

| 能力 | 说明 | 解锁条件 |
|------|------|----------|
| **驯服** | 捕捉和驯服良性变异生物 | 初始 |
| **培养** | 培养宠物，使其进化 | 宠物系统解锁 |
| **对抗** | 与基因崩溃的怪物战斗 | 初始 |
| **净化** | 净化被污染的区域 | 剧情解锁 |
| **提取** | 从变异生物体内提取神秘物质 | 击败敌人自动获取 |

### 变异的双刃剑

- **好处**：宠物会变强，可以帮助玩家
- **坏处**：过度依赖变异可能导致危险
- **平衡**：玩家需要在利用变异和控制变异之间找到平衡
