## 📅 大事年表

### 黑暗的起点（2040-2049）

| 年份 | 事件 | 影响 |
|------|------|------|
| **2040年** | 环海之国开始向太平洋排放核废水 | 海洋生态系统开始受到污染 |
| **2040年** | 混沌博士秘密加强核废水的变异诱导性 | 加速灾难爆发（混沌博士的阴谋） |
| **2041年** | 多国抗议，但环海之国无视国际压力继续排放 | 国际关系紧张 |
| **2042年** | 首批海洋生物出现异常变异报告 | 被官方压制，视为"谣言" |
| **2043年** | 沿海渔民失踪事件频发 | 恐慌开始蔓延 |
| **2044年** | 海洋生物大规模变异 | 沿海城市进入戒备状态 |
| **2045年** | 变异海洋生物获得两栖能力，开始登陆 | 沿海城市沦陷，人类意识到危机的严重性 |
| **2046年** | 生态异变初现，陆地生物也开始变异 | 全球恐慌加剧 |
| **2047年** | 各国互相指责，国际关系极度紧张 | 战争阴云密布 |
| **2048年** | 核废水排放国政府垮台，真相被揭露 | 但为时已晚 |
| **2049年** | 全球进入紧急状态，各国封锁海岸线 | 世界经济崩溃 |

### 末日降临（2050-2059）

| 年份 | 事件 | 影响 |
|------|------|------|
| **2050年** | 核战争爆发，各国因环境变化互相指责开战 | 人类文明的终结开始 |
| **2051年** | 核战争导致环境彻底崩溃，异化现象爆发 | 变异速度急剧加快 |
| **2052年** | 核战争摧毁大部分现代化武器和基础设施 | 人类失去科技优势 |
| **2053年** | 第一次"变异潮"爆发，内陆城市告急 | 人类防线全面崩溃 |
| **2054年** | 人类文明崩溃，政府机构瓦解 | 社会秩序彻底崩塌 |
| **2055年** | 大规模变异潮爆发，全球陷入混乱 | 人类数量锐减 |
| **2056年** | 残存人类开始组建据点求生 | 废土时代开始萌芽 |
| **2057年** | 人类开始驯服变异生物作为战斗伙伴 | 宠物系统起源 |
| **2058年** | 混沌博士开始他的疯狂实验 | 新的威胁出现 |
| **2059年** | 世界进入"废土时代" | 人类在废墟中求生，依靠变异生物和旧时代武器 |

### 废土时代（2060-2099）

| 年份 | 事件 | 影响 |
|------|------|------|
| **2060年** | 废土时代正式开始 | 人类在废墟中挣扎求生 |
| **2070年** | 各势力格局基本形成 | 净化者、钢铁军团、拾荒者、掠夺者崛起 |

| **2099年** | 游戏开始前夕 | 角色在废墟城市中醒来 |

### 游戏开始（2100年）

| 时间 | 状态 | 说明 |

## 🎭 重要历史人物

### 环海之国最后一任首相

- **姓名**：未公开
- **结局**：政府垮台后失踪
- **评价**：历史的罪人，或说是被利用的棋子

### 疯狂科学家（最终BOSS）

- **代号**：Doctor Chaos / 混沌博士
- **背景**：环海之国（帝国）基因工程首席科学家
- **现状**：隐藏在沉睡的活火山内部，继续着疯狂的实验
- **动机**：
  - **真实目的**：用混沌力量净化世界，消除感染（代价是消灭现有生物）
  - **表面目的**：实现人类进化，创造完美生物
- **背景故事**：
  - 早期：研究被帝国政府禁止，怀恨在心
  - 中期：秘密加强核废水的变异诱导性，加速灾难爆发
  - 转变期：帝国垮台后开始反思，发现混沌力量可以净化世界
  - 游戏开始：执行"净化计划"，玩家需要阻止或理解他

### 实验体项目

- **项目名称**：完美人类计划
- **实验体数量**：11人（编号01-11）
- **实验目的**：创造对感染免疫的新人类
- **实验体状态**：
  - 01-06号：早期实验体，失败/死亡
  - 07号：玩家，存活，失忆，感染抗性高
  - 08号：艾米，存活，部分失忆，感染抗性中
  - 09号：杰克，存活，部分失忆，感染抗性中
  - 10号：莉娜，存活，部分失忆，感染抗性中
  - 11号：被囚禁的实验体，存活，感染抗性低

### 混沌博士与帝国政府的关系

```
早期（2040年之前）：
    ├── 混沌博士是帝国基因工程首席科学家
    ├── 研究变异基因工程，试图证明变异可以拯救人类
    └── 研究被帝国政府禁止，怀恨在心

中期（2040-2050年）：
    ├── 秘密加强核废水的变异诱导性
    ├── 加速灾难爆发，证明自己的研究价值
    └── 帝国政府垮台后开始反思

转变期（2050-2070年）：
    ├── 发现混沌力量可以净化世界
    ├── 制定"净化计划"，代价是消灭现有生物
    └── 继续实验，寻找净化世界的方法

游戏开始（2100年）：
    ├── 执行"净化计划"
    ├── 创造终极变异体作为武器
    └── 玩家需要阻止或理解他
```

## 📖 术语解释

| 术语 | 解释 |
|------|------|
| **环海之国** | 核废水排放国，又称"帝国"，政府垮台后已不存在 |
| **帝国** | 环海之国的别称，因该国曾自称为"帝国"而得名 |
| **废土时代** | 2059年政府崩溃后，世界进入的混乱时期 |
| **变异潮** | 变异生物大规模迁徙或攻击的现象 |
| **净化** | 恢复被污染环境的过程 |
| **基因崩溃** | 变异失败，生物失去理智变成怪物 |
| **良性变异** | 变异成功，生物保留理智并获得能力 |
| **抗辐射变异物质** | 能够中和核辐射的特殊物质，传说存在于终极BOSS体内 |
| **旧时代武器** | 核战争前生产的武器，稀有且珍贵 |
| **变异生物伙伴** | 被驯服的变异生物，可协助战斗 |

## 🔫 武器与生存方式

### 核战争的影响

```
核战争爆发（2050年）
        ↓
现代化武器和基础设施被摧毁
        ↓
人类失去科技优势
        ↓
无法生产新武器
        ↓
只能依靠：
├── 旧时代武器（稀有，从废墟中拾取）
├── 变异生物伙伴（驯服的变异生物）
├── 简易武器（手工制作）
└── 元素力量（部分人类觉醒的能力）
```

### 武器类型

| 类型 | 来源 | 稀有度 | 说明 |
|------|------|--------|------|
| **旧时代武器** | 废墟探索 | ★★★★★ | 核战争前生产的武器，威力强大但稀有 |
| **变异武器** | 变异生物材料 | ★★★★☆ | 用变异生物材料制作，带有特殊效果 |
| **手工武器** | 自制 | ★★☆☆☆ | 简单但实用，材料易得 |
| **元素武器** | 元素力量 | ★★★☆☆ | 附带元素伤害的武器 |

### 生存方式

```
废土人类的生存依赖：

1. 变异生物伙伴
   ├── 战斗协助
   ├── 资源获取
   ├── 骑乘移动
   └── 特殊能力

2. 旧时代武器
   ├── 远程武器（枪械，弹药稀缺）
   ├── 近战武器（刀剑，相对常见）
   └── 防具（护甲，保护身体）

3. 元素力量
   ├── 火焰
   ├── 冰霜
   ├── 雷电
   ├── 毒素
   ├── 辐射
   └── 净化

4. 团队合作
   ├── 组建队伍
   ├── 分工协作
   └── 资源共享
```
