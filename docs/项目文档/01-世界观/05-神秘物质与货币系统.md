# 神秘物质与货币系统

> *"这种物质能延缓死亡，也能引发贪婪。在这片废土上，它比黄金更珍贵。"*

## 💎 神秘物质概述

### 什么是神秘物质？

神秘物质是变异生物体内产生的一种特殊结晶，具有以下特性：

| 特性 | 说明 |
|------|------|
| **来源** | 变异生物的核心部位 |
| **外观** | 发光的晶体，颜色随品质变化 |
| **作用1** | 延缓人类感染症状，延续生命 |
| **作用2** | 作为交易货币，购买物资 |
| **作用3** | 净化环境的关键材料 |
| **稀有度** | 品质越高越稀有 |

### 为什么神秘物质如此重要？

```
人类面临的困境：
    │
    ├── 被感染后会逐渐死亡
    │
    ├── 没有已知的治愈方法
    │
    └── 唯一能延缓死亡的是神秘物质

因此：
    │
    ├── 神秘物质 = 生存的希望
    │
    ├── 神秘物质 = 交易的货币
    │
    └── 神秘物质 = 各势力争夺的焦点
```

## 📊 神秘物质品质体系

### 品质分级

**说明**："精纯神秘物质"是"稀有神秘物质"（III级）的别名，在剧情和势力文档中常使用"精纯"一词。

| 品质 | 名称 | 别名 | 颜色 | 延缓效果 | 获取难度 | 价值 |
|------|------|------|------|----------|----------|------|
| **I** | 普通 | - | ⚪ 白色 | 1天 | 容易 | 1 单位 |
| **II** | 精良 | - | 🟢 绿色 | 3天 | 较少 | 5 单位 |
| **III** | 稀有 | **精纯** | 🔵 蓝色 | 7天 | 稀有 | 20 单位 |
| **IV** | 史诗 | - | 🟣 紫色 | 30天 | 极稀有 | 100 单位 |
| **传说** | 传说 | - | 🟡 金色 | 永久（净化） | 未知 | ？？？ |

### 品质与来源

```
神秘物质品质取决于：
    │
    ├── 变异生物的等级
    │   ├── I级变异体 → 普通神秘物质
    │   ├── II级变异体 → 精良神秘物质
    │   ├── III级变异体 → 稀有神秘物质
    │   ├── IV级变异体 → 史诗神秘物质
    │   └── V级变异体 → 传说神秘物质（极低概率）
    │
    ├── 变异生物的类型
    │   ├── 普通敌人 → 品质较低
    │   ├── 精英敌人 → 品质中等
    │   └── BOSS敌人 → 品质较高
    │
    └── 击败方式
        ├── 快速击杀 → 品质可能降低
        └── 完美击杀 → 品质可能提升
```

| 旧世界货币 | 新世界货币 |

```
    │
```

## 📈 经济平衡

### 收入与支出

```
玩家收入来源：
    │
    ├── 战斗掉落（主要）
    ├── 任务奖励（次要）
    ├── 探索发现（随机）
    └── 交易利润（可选）

玩家支出项目：
    │
    ├── 购买物资（消耗品、装备）
    ├── 捕捉宠物（捕捉球、诱饵）
    ├── 净化感染（神秘物质消耗）
    ├── 宠物培养（进化材料）
    └── 据点建设（建造材料）
```

### 难度曲线

| 游戏阶段 | 收入水平 | 支出水平 | 经济状态 |
|----------|----------|----------|----------|
| 早期（1-20级） | 低 | 低 | 勉强维持 |
| 中期（21-50级） | 中 | 中 | 基本平衡 |
| 后期（51-80级） | 高 | 高 | 略有盈余 |
| 终局（81-100级） | 很高 | 很高 | 追求极致 |

## 🔮 特殊用途

### 感染延缓

```
使用神秘物质延缓感染：
    │
    ├── 打开角色面板
    │
    ├── 选择"使用神秘物质"
    │
    ├── 选择数量
    │
    ├── 确认使用
    │
    └── 感染度下降

公式：
感染度下降 = 神秘物质数量 × 品质系数

品质系数：
    I级：1天/单位
    II级：3天/单位
    III级：7天/单位
    IV级：30天/单位
    传说：永久
```

### 净化材料

神秘物质是制作净化道具的关键材料：

| 净化道具 | 所需材料 | 效果 |
|----------|----------|------|
| 基础净化药剂 | 10 普通 | 净化小范围区域 |
| 中级净化药剂 | 5 精良 | 净化中等区域 |
| 高级净化药剂 | 3 稀有 | 净化大范围区域 |
| 终极净化装置 | 1 史诗 + 特殊材料 | 净化整个区域 |

### 宠物进化

某些宠物进化需要消耗神秘物质：

| 进化类型 | 所需材料 | 说明 |
|----------|----------|------|
| 基础进化 | 5 普通 | Lv.30进化 |
| 高级进化 | 3 精良 | Lv.60进化 |
| 终极进化 | 1 稀有 | Lv.90进化 |

```
    └── 净化世界，建立新时代

抗辐射变异物质：
    │
    ├── 是最顶级的神秘物质

    └── 能净化整个世界
```
