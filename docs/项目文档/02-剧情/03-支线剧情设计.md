# 支线剧情设计

## 支线剧情类型

### 1. 角色支线

#### 同伴支线

| 同伴 | 支线数量 | 主要内容 | 解锁条件 |
|------|----------|----------|----------|
| **艾米** | 5个 | 身世、能力、过去、未来、羁绊 | 第一章加入 |
| **杰克** | 5个 | 背景、使命、牺牲、成长、羁绊 | 第一章加入 |
| **莉娜** | 5个 | 秘密、研究、发现、选择、羁绊 | 第一章加入 |
| **老者** | 3个 | 过去、真相、遗产 | 第一章完成 |

#### 艾米支线剧情

**支线1：记忆碎片**
```
艾米最近总是做噩梦，梦见一些奇怪的片段。
"我梦见...一个实验室...很多人...
他们叫我08号...我是不是..."

【任务】帮助艾米找回记忆
【奖励】艾米好感度+50，记忆碎片x1
```

**选择1：如何帮助艾米**
- [陪她冥想] → 安全但缓慢
- [使用记忆道具] → 快速但有风险
- [寻找专家] → 需要特定NPC

**支线2：能力觉醒**
```
艾米的能力突然失控，差点伤到同伴。
"我...我控制不住...这力量太强了..."

【任务】帮助艾米控制能力
【奖励】艾米能力提升，羁绊技能解锁
```

**选择2：控制方法**
- [训练控制] → 耗时但安全
- [使用抑制器] → 快速但依赖道具
- [寻找其他实验体] → 可能有帮助

**支线3：过去的真相**
```
艾米恢复了部分记忆：
"我想起来了...07号是...是你！
我们曾经是...兄妹..."

【任务】确认艾米的记忆
【奖励】羁绊关系确认，专属剧情解锁
```

**选择3：如何对待艾米**
- [接受她] → 兄妹关系确认
- [需要时间] → 关系保持现状
- [质问她] → 关系紧张

**支线4：未来选择**
```
艾米面临选择：
"我可以选择...用我的力量保护世界，
但可能会...永远消失..."

【任务】帮助艾米做出选择
【奖励】艾米最终形态解锁
```

**选择4：支持艾米**
- [支持她的选择] → 艾米牺牲
- [阻止她] → 寻找其他方法
- [一起承担] → 共同面对

**支线5：羁绊深化**
```
经过一系列事件，你和艾米的羁绊达到顶峰。
"无论发生什么...你都是我最重要的人..."

【任务】完成羁绊任务
【奖励】羁绊技能完全体，专属结局
```

#### 杰克支线剧情

**支线1：军人的过去**
```
杰克曾经是军人，在核战争中失去了战友。
"他们...都死了...只有我活了下来..."

【任务】帮助杰克面对过去
【奖励】杰克好感度+50，战斗技能提升
```

**选择1：如何帮助杰克**
- [陪他祭奠战友] → 情感支持
- [帮他复仇] → 战斗任务
- [让他放下] → 心理辅导

**支线2：使命与责任**
```
杰克收到军队的联络：
"有任务...关于混沌博士...
但需要牺牲..."

【任务】帮助杰克选择
【奖励】杰克技能树解锁
```

**选择2：杰克的选择**
- [接受任务] → 杰克执行任务
- [拒绝任务] → 杰克留在队伍
- [一起执行] → 团队任务

**支线3：牺牲精神**
```
在关键时刻，杰克选择牺牲自己保护同伴。
"这是...军人的职责..."

【任务】阻止或接受杰克的牺牲
【奖励】杰克生死选择
```

**选择3：杰克的命运**
- [阻止他] → 杰克存活但受伤
- [接受] → 杰克牺牲
- [寻找替代方案] → 高风险

**支线4：成长与改变**
```
杰克逐渐从过去的阴影中走出。
"我...不再是为了复仇而战...
是为了保护现在..."

【任务】帮助杰克成长
【奖励】杰克最终形态解锁
```

**选择4：杰克的未来**
- [支持他] → 杰克成为领袖
- [让他留下] → 杰克成为导师
- [让他离开] → 杰克独自旅行

**支线5：战友的遗产**
```
杰克发现了战友留下的遗物：
"这是...他们留给我的...
我要继续他们的使命..."

【任务】完成战友的遗愿
【奖励】杰克专属装备，羁绊技能
```

### 3. 探索支线

#### 废墟城市支线

**支线1：城市秘密**
```
你在废墟城市中发现一个秘密通道：
"这里...通往地下...
有什么东西..."

【任务】探索秘密通道
【奖励】隐藏道具，城市秘密
```

**选择1：探索方式**
- [独自探索] → 危险但自由
- [带同伴] → 安全但可能暴露
- [先侦查] → 了解情况再决定

**支线2：幸存者营地**
```
你发现一个幸存者营地：
"我们...在这里生活...
需要帮助..."

【任务】帮助幸存者
【奖励】营地支援，物资奖励
```

**选择2：帮助方式**
- [提供物资] → 消耗资源
- [帮助建设] → 耗时但长期收益
- [训练他们] → 提升营地防御

**支线3：城市遗迹**
```
城市深处有未探索的遗迹：
"那里...据说有宝藏...
但也很危险..."

【任务】探索城市遗迹
```

- [独自探索] → 危险但独享
- [先侦查] → 了解情况
