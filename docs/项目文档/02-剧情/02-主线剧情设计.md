# 主线剧情设计

## 故事背景

### 时间线

| 时间 | 事件 | 说明 |
|------|------|------|
| **2040年** | 核废水排放开始 | "环海之国"开始向海洋排放核废水 |
| **2045年** | 第一批变异生物登陆 | 沿海城市沦陷，人类意识到危机的严重性 |
| **2048年** | 帝国政府垮台 | 真相被揭露，但为时已晚 |
| **2050年** | 核战争爆发 | 各国因环境变化互相指责，爆发核战争 |
| **2055年** | 大规模变异潮爆发 | 全球陷入混乱，人类数量锐减 |
| **2060年** | 废土时代正式开始 | 人类在废墟中挣扎求生 |
| **2070年** | 各势力格局基本形成 | 净化者、钢铁军团、拾荒者、掠夺者崛起 |
| **2100年** | 游戏开始 | 角色在废墟城市中醒来 |

### 核心冲突

**主要矛盾**：
- 人类 vs 变异生物
- 各势力之间的权力斗争
- 混沌博士的阴谋 vs 人类存亡

**深层矛盾**：
- 科技发展 vs 生态平衡
- 人性善恶 vs 生存压力
- 记忆与身份 vs 现实与选择

### 玩家身份背景

**玩家身份**：07号实验体

**完整背景故事**：

```
核战争前（2040-2050年）：
    │
    ├── 玩家是年轻的基因工程研究员
    │
    ├── 参与了混沌博士的实验项目
    │
    ├── 被选为"完美人类"实验的实验体
    │
    └── 编号07号实验体

核战争期间（2050-2055年）：
    │
    ├── 玩家发现了混沌博士的疯狂实验
    │
    ├── 玩家反对混沌博士的做法
    │
    ├── 被混沌博士强制进入休眠
    │
    └── 休眠期间身体被改造，停止衰老

休眠期间（2055-2100年）：
    │
    ├── 玩家在休眠舱中沉睡
    │
    ├── 身体被改造，获得了特殊能力
    │
    ├── 与宠物沟通的能力被激活
    │
    └── 部分记忆被抹除

游戏开始（2100年）：
    │
    ├── 玩家被同伴唤醒
    │
    ├── 失去了大部分记忆
    │
    ├── 身体仍然是年轻状态
    │
    └── 需要寻找自己的身世
```

**玩家特殊能力**：
1. **与宠物沟通**：可以与变异生物建立联系
2. **元素力量觉醒**：可以使用元素技能
3. **休眠改造**：身体停止衰老，保持年轻状态
4. **记忆碎片**：部分记忆可以通过特殊事件恢复
5. **感染抗性**：对感染有一定抗性（来自休眠改造）

**实验体编号**：
| 编号 | 身份 | 状态 | 感染抗性 |
|------|------|------|----------|
| 01-06号 | 早期实验体 | 失败/死亡 | 无 |
| 07号 | 玩家 | 存活，失忆 | 高 |
| 08号 | 艾米 | 存活，部分失忆 | 中 |
| 09号 | 杰克 | 存活，部分失忆 | 中 |
| 10号 | 莉娜 | 存活，部分失忆 | 中 |
| 11号 | 被囚禁的实验体 | 存活 | 低 |

### 感染系统剧情融入

**感染机制**：
```
玩家状态栏显示：
┌─────────────────────────────────┐
│  感染度：15%  [███████░░░░░░░]  │
│  神秘物质：125 单位              │
│  预计剩余时间：约30天            │
└─────────────────────────────────┘

规则：
- 感染度达到100%时，游戏结束
- 使用神秘物质可延缓感染（按天数计算）
- 不同品质的神秘物质延缓效果不同

神秘物质延缓效果：
| 品质 | 名称 | 延缓时间 | 说明 |
|------|------|----------|------|
| I级 | 普通 | 1天 | 基础延缓 |
| II级 | 精良 | 3天 | 较好延缓 |
| III级 | 稀有（精纯） | 7天 | 很好延缓 |
| IV级 | 史诗 | 30天 | 极好延缓 |
| 传说 | 传说 | 永久（净化） | 完全消除感染 |
```

**剧情中的感染事件**：

| 章节 | 感染事件 | 影响 |
|------|----------|------|
| **第一章** | 在废墟城市探索时感染度缓慢增长 | 教学感染系统 |
| **第一章** | 进入高辐射区域，感染度快速增加 | 增加挑战 |
| **第二章** | 发现神秘物质可以降低感染度 | 提供解决方案 |
| **第二章** | 混沌博士的实验体对感染免疫 | 揭示真相 |
| **第三章** | 同伴感染，需要寻找神秘物质 | 增加剧情张力 |
| **第三章** | 混沌地带感染度极高 | 增加难度 |
| **第四章** | 混沌博士的"净化计划"与感染有关 | 揭示最终真相 |

**感染系统与剧情的结合**：

1. **第一章：废土求生**
   - 玩家刚醒来时感染度为0%
   - 探索废墟城市时感染度缓慢增长
   - 教学：如何使用神秘物质降低感染度

2. **第二章：真相探索**
   - 进入污染荒野，感染度增长加快
   - 发现神秘物质的重要作用
   - 混沌博士的实验体对感染免疫（揭示真相）

3. **第三章：对抗混沌**
   - 同伴可能感染，需要玩家拯救
   - 混沌地带感染度极高，需要特殊装备
   - 感染系统成为剧情推动力

4. **第四章：终极决战**
   - 混沌博士的"净化计划"与感染有关
   - 玩家需要在感染度达到100%前完成任务
   - 感染系统影响最终结局

**感染值计算公式**：
```
每日感染增长 = 基础增长 + 区域系数 × 时间系数

基础增长：1%/天
区域系数：
- 废墟城市：1.0
- 污染荒野：1.5
- 混沌地带：3.0
- 混沌实验室：5.0

时间系数：随游戏时间增加
- 第一章：1.0
- 第二章：1.2
- 第三章：1.5
- 第四章：2.0

神秘物质效果：
- 普通神秘物质：降低5%感染度
- 精纯神秘物质：降低15%感染度
- 终极神秘物质：降低30%感染度
```

### 游戏世界设定

**核战争的影响**：
- 核战争摧毁了大部分现代化武器和基础设施
- 人类失去了科技优势，无法生产新武器
- 只能依靠从废墟中拾取的**旧时代武器**（稀有且珍贵）
- **变异生物伙伴**成为主要战斗力量（宠物系统）
- 部分人类觉醒了**元素力量**（火焰、冰霜、雷电等）

**玩家的战斗方式**：
1. **宠物战斗**：驯服变异生物，协助战斗
2. **武器战斗**：使用旧时代武器或手工武器
3. **元素力量**：使用元素技能造成伤害
4. **团队合作**：与同伴组队，分工协作

## 第一章：废土求生（1-30级）

### 章节概述

**主题**：生存、探索、身份寻找  
**地点**：废墟城市（4个区域）  
**主要NPC**：老者、艾米、杰克、莉娜  
**主要敌人**：变异鼠、变异犬、流浪者、小偷

### 剧情流程

#### 开场剧情（1-5级）

**场景1：醒来**
```
你从昏迷中醒来，发现自己躺在一堆废墟中。
周围是破败的建筑和生锈的车辆。
你不记得自己是谁，也不知道发生了什么。
唯一能确定的是：你还活着。

【系统提示】你失去了记忆，需要寻找身世线索。
```

**选择1：探索周围**
- [查看周围环境] → 获得地图碎片
- [寻找有用物品] → 获得基础道具
- [呼喊求助] → 遇到老者

**场景2：遇到老者**
```
一位衣衫褴褛的老者向你走来。
"年轻人，你醒了？你已经昏迷了三天。
这里是废墟城市，2100年的世界。
你...你不记得了吗？"

【老者】废墟城市的退休教师，知道很多秘密
```

**选择2：与老者对话**
- [询问身世] → 老者提供线索
- [询问世界现状] → 了解废土背景
- [表示感谢] → 获得老者好感

#### 探索剧情（6-15级）

**场景3：遇到艾米**
```
你在废墟中发现一个受伤的女孩。
她看起来和你年龄相仿，身上有奇怪的伤痕。
"请...请帮帮我...有变异生物在追我..."

【艾米】废墟城市的幸存者，拥有特殊能力
```

**选择3：帮助艾米**
- [立即帮助] → 与变异鼠战斗
- [先观察情况] → 了解更多再决定
- [提供道具帮助] → 消耗道具，获得艾米信任

**场景4：变异鼠巢穴**
```
你决定帮助艾米，前往变异鼠巢穴。
巢穴中阴暗潮湿，到处是变异鼠的嘶叫声。
突然，一群变异鼠向你们扑来！

【战斗】变异鼠 x5
```

**选择4：战斗策略**
- [正面攻击] → 标准战斗
- [使用陷阱] → 消耗道具，获得优势
- [让艾米帮忙] → 艾米加入战斗

#### 阵营选择剧情（16-25级）

**场景5：势力接触**
```
随着你在废墟城市中声名鹊起，
四大势力开始关注你：

• 净化者 - 净化世界的正义组织
• 钢铁军团 - 军事化的秩序组织
• 拾荒者 - 生存至上的中立组织
• 掠夺者 - 弱肉强食的混乱组织

每个势力都邀请你加入。

【系统提示】选择阵营将影响后续剧情
```

**选择5：阵营选择**
- [加入净化者] → 解锁净化技能路线
- [加入钢铁军团] → 解锁战斗技能路线
- [加入拾荒者] → 解锁生存技能路线
- [加入掠夺者] → 解锁掠夺技能路线
- [暂不加入] → 继续探索，稍后选择

#### 章节高潮（26-30级）

**场景6：发现线索**
```
你在废墟城市深处发现了一个秘密实验室。
实验室中有大量关于核战争的资料，
还有一个名字：混沌博士。

资料显示，核战争并非意外，
而是有人精心策划的阴谋。

【关键线索】混沌博士与核战争有关
```

**选择6：下一步行动**
- [深入调查] → 发现更多线索
- [告诉同伴] → 召集同伴讨论
- [前往污染荒野] → 进入第二章

## 第二章：真相探索（31-60级）

### 章节概述

**主题**：真相、阴谋、选择  
**地点**：污染荒野（4个区域）  
**主要NPC**：科学家幽灵、混沌使者、各阵营领袖  
**主要敌人**：变异生物、混沌怪物、敌对势力

### 剧情流程

#### 进入荒野（31-40级）

**场景1：离开城市**
```
你决定离开废墟城市，前往污染荒野。
老者送你到城门口：
"年轻人，荒野比城市更危险。
但那里也有更多真相。
记住，不是所有看起来像敌人的人都是敌人..."

【系统提示】进入第二章，新区域开放
```

**选择1：离开方式**
- [直接前往] → 遭遇随机事件
- [准备充分再走] → 消耗时间但更安全
- [与同伴一起] → 同伴加入队伍

**场景2：荒野第一夜**
```
你在荒野中扎营，夜晚传来奇怪的声音。
帐篷外出现一个模糊的身影：
"我知道你在找什么...混沌博士的真相。
我可以告诉你...但你需要付出代价..."

【神秘人】身份不明，似乎知道很多
```

**选择2：与神秘人交易**
- [接受交易] → 获得线索，但付出代价
- [拒绝交易] → 神秘人离开
- [尝试抓住他] → 追逐战

#### 发现遗迹（41-50级）

**场景3：古代遗迹**
```
根据线索，你发现了一个古代遗迹。
遗迹中有大量关于核战争前的资料，
还有一个全息投影：

"我是张博士，核战争前的科学家。
如果你看到这个，说明战争已经爆发了。
真相是...战争不是意外...
是'环海之国'的阴谋..."

【张博士】核战争前的科学家，留下线索
```

**选择3：遗迹探索**
- [继续听下去] → 了解完整真相
- [查看周围环境] → 发现隐藏物品
- [记录信息] → 获得任务物品

**场景4：混沌使者出现**
```
突然，一个身穿黑袍的人出现在你面前：
"你发现了不该发现的东西。
混沌博士让我来处理你..."
混沌使者向你发起攻击！

【战斗】混沌使者 x1（精英敌人）
```

**选择4：战斗策略**
- [全力攻击] → 标准战斗
- [使用遗迹中的装置] → 机关辅助战斗
- [尝试谈判] → 可能失败，但有机会了解真相

#### 身世揭晓（51-60级）

**场景5：记忆碎片**
```
在战斗中，你受到重击，记忆开始恢复：
"你...你是07号实验体...
我们曾经是同事...
混沌博士...他背叛了我们..."

你想起了一些碎片：你曾是科学家，
参与过核研究，但后来反对战争。

【关键信息】你是07号实验体，曾是科学家
```

**选择5：面对真相**
- [完全恢复记忆] → 获得完整背景
- [拒绝接受] → 暂时逃避
- [询问更多细节] → 了解同伴身份

**场景6：同伴真相**
```
你发现你的同伴也有秘密：
• 艾米 - 08号实验体，你的"妹妹"
• 杰克 - 09号实验体，你的"兄弟"
• 莉娜 - 10号实验体，你的"姐姐"

你们都是混沌博士的实验体，
被派来执行任务，但你们反抗了。

【系统提示】同伴关系加深，解锁羁绊技能
```

**选择6：如何对待同伴**
- [接受他们] → 同伴忠诚度提升
- [需要时间接受] → 同伴忠诚度不变
- [质问他们] → 同伴忠诚度下降

## 第三章：对抗混沌（61-90级）

### 章节概述

**主题**：联合、牺牲、抉择  
**地点**：混沌地带（4个区域）  
**主要NPC**：各阵营领袖、混沌博士、实验体同伴  
**主要敌人**：混沌军团、高级混沌怪物、BOSS

### 剧情流程

#### 联合势力（61-70级）

**场景1：召集会议**
```
你决定联合各势力对抗混沌博士。
在废弃的军事基地中，各势力领袖齐聚一堂：

• 净化者领袖：林清月
• 钢铁军团领袖：雷克斯
• 拾荒者领袖：艾伦
• 掠夺者领袖：凯恩

"混沌博士的势力日益强大，
我们必须联合起来..."

【系统提示】联合势力成功，解锁联合技能
```

**选择1：联合策略**
- [直接进攻] → 高风险高回报
- [分阶段进攻] → 稳妥但耗时
- [使用计谋] → 需要特定道具

**场景2：分歧**
```
在制定战略时，各势力产生分歧：
• 林清月主张优先净化污染
• 雷克斯主张直接攻击核心
• 艾伦主张保护平民
• 凯恩主张掠夺资源

"我们需要一个统一的策略..."

【系统提示】选择将影响联合势力的走向
```

**选择2：统一策略**
- [采纳林清月的策略] → 净化优先
- [采纳雷克斯的策略] → 攻击优先
- [采纳艾伦的策略] → 保护优先
- [采纳凯恩的策略] → 掠夺优先

#### 攻打据点（71-80级）

**场景3：第一个据点**
```
联合军向混沌博士的第一个据点发起进攻。
据点防守严密，战斗异常激烈。

"所有人注意！前方发现大量混沌怪物！
准备战斗！"

【战斗】混沌怪物 x20 + 精英怪 x5
```

**选择3：战斗指挥**
- [正面强攻] → 标准战斗
- [分兵包抄] → 战术优势
- [使用重武器] → 消耗资源

**场景4：据点内部**
```
成功突破防线后，你进入据点内部。
发现大量关于混沌力量的研究资料，
还有一个囚犯：

"救救我...我是...我是11号实验体...
混沌博士...他要用我们...毁灭世界..."

【11号实验体】被囚禁的实验体，知道重要信息
```

**选择4：如何对待囚犯**
- [立即解救] → 获得盟友
- [先获取信息] → 了解更多再决定
- [交给同伴处理] → 同伴决定

#### 牺牲抉择（81-90级）

**场景5：无法避免的牺牲**
```
在攻打最后一个据点时，你面临艰难选择：
"混沌博士启动了自毁程序！
我们必须在30分钟内撤离！
但是...艾米被困在核心区域..."

你必须在拯救同伴和完成任务之间选择。

【系统提示】这个选择将影响结局
```

**选择5：牺牲抉择**
- [拯救艾米] → 任务失败，但艾米存活
