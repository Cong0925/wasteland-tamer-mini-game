# 剧情系统总览

## 系统概述

剧情系统是"末日废土"的灵魂，定义了游戏的故事背景、主线剧情、支线任务和角色对话。本系统采用纯文字选择类RPG形式，通过文字描述和选项选择推进剧情。

## 剧情结构

### 时间线

| 时间 | 事件 | 说明 |
|------|------|------|
| **2040年** | 核废水排放开始 | "环海之国"开始向海洋排放核废水 |
| **2045年** | 第一批变异生物登陆 | 沿海城市沦陷，人类意识到危机的严重性 |
| **2048年** | 帝国政府垮台 | 真相被揭露，但为时已晚 |
| **2050年** | 核战争爆发 | 各国因环境变化互相指责，爆发核战争 |
| **2055年** | 大规模变异潮爆发 | 全球陷入混乱，人类数量锐减 |
| **2060年** | 废土时代正式开始 | 人类在废墟中挣扎求生 |
| **2070年** | 各势力格局基本形成 | 净化者、钢铁军团、拾荒者、掠夺者崛起 |
| **2100年** | 游戏开始 | 角色在废墟城市中醒来 |

### 故事主线

| 章节 | 名称 | 内容 | 等级范围 |
|------|------|------|----------|
| **第一章** | 废土求生 | 角色在废墟城市中求生，了解世界背景 | 1-30级 |
| **第二章** | 真相探索 | 深入污染荒野，发现核战争真相 | 31-60级 |
| **第三章** | 对抗混沌 | 进入混沌地带，对抗混沌博士的势力 | 61-90级 |
| **第四章** | 终极决战 | 进入混沌实验室，最终决战 | 91-100级 |

### 剧情类型

| 类型 | 数量 | 说明 |
|------|------|------|
| **主线剧情** | 4章 | 推动故事发展的核心剧情 |
| **支线任务** | 50+个 | 丰富世界观的辅助剧情 |
| **角色剧情** | 20+个 | 角色个人故事线 |
| **隐藏剧情** | 10+个 | 特殊条件触发的隐藏内容 |

### 游戏世界设定

**核战争的影响**：
- 核战争摧毁了大部分现代化武器和基础设施
- 人类失去了科技优势，无法生产新武器
- 只能依靠从废墟中拾取的**旧时代武器**（稀有且珍贵）
- **变异生物伙伴**成为主要战斗力量（宠物系统）
- 部分人类觉醒了**元素力量**（火焰、冰霜、雷电等）

**玩家的战斗方式**：
1. **宠物战斗**：驯服变异生物，协助战斗
2. **武器战斗**：使用旧时代武器或手工武器
3. **元素力量**：使用元素技能造成伤害
4. **团队合作**：与同伴组队，分工协作

## 剧情演出方式

### 纯文字选择类形式

由于游戏是微信小程序纯文字选择类RPG，剧情演出采用以下形式：

1. **文字描述**：通过文字描述场景、角色、事件
2. **选项选择**：玩家通过点击选项推进剧情
3. **对话框**：角色对话通过对话框展示
4. **分支选择**：关键剧情点提供不同选择，影响后续发展

## 剧情关键系统

### 1. 声望系统

剧情选择会影响玩家与各势力的声望，声望高低会影响：

| 声望等级 | 数值范围 | 影响 |
|----------|----------|------|
| **仇恨** | -1000 ~ -500 | 敌对行为，主动攻击 |
| **敌对** | -500 ~ -100 | 不友好，高价交易 |
| **中立** | -100 ~ 100 | 正常交互 |
| **友好** | 100 ~ 500 | 友好交互，折扣交易 |
| **崇敬** | 500 ~ 1000 | 特殊任务，专属奖励 |

### 2. 阵营系统

玩家可选择加入不同阵营，阵营选择影响：

| 阵营 | 立场 | 领袖 | 特色 | 专属内容 |
|------|------|------|------|----------|
| **净化者** | 正义 | 林清月 | 净化世界 | 净化技能、净化装备 |
| **钢铁军团** | 秩序 | 雷克斯 | 军事纪律 | 战斗技能、攻击装备 |
| **拾荒者** | 中立 | 艾伦 | 生存至上 | 生存技能、防御装备 |
| **掠夺者** | 混乱 | 凯恩 | 弱肉强食 | 掠夺技能、掠夺装备 |
| **混沌博士** | 疯狂 | 混沌博士 | 最终BOSS | - |

### 3. 选择分支系统

关键剧情点提供不同选择，影响：

| 影响类型 | 说明 | 示例 |
|----------|------|------|
| **剧情走向** | 影响后续剧情发展 | 选择帮助A或B |
| **声望变化** | 影响与势力的关系 | 救人增加声望 |
| **获得/失去** | 获得道具或失去机会 | 选择宝箱内容 |
| **角色生死** | 影响角色存亡 | 关键选择决定生死 |

### 4. 感染系统

感染系统是游戏的核心生存机制，影响玩家的探索和决策：

| 区域 | 感染增长速度 | 说明 |
|------|--------------|------|
| **废墟城市** | 1%/天 | 相对安全 |
| **污染荒野** | 1.5%/天 | 需要防护 |
| **混沌地带** | 3%/天 | 非常危险 |
| **混沌实验室** | 5%/天 | 极度危险 |

**感染系统影响**：
- 感染度达到100%时，游戏结束
- 使用神秘物质可降低感染度
- 高感染度会影响角色属性
- 感染系统推动玩家探索和决策

**剧情中的感染事件**：
- 同伴可能感染，需要玩家拯救
- 高辐射区域感染度快速增长
- 混沌博士的实验体对感染免疫
- 感染系统与最终结局相关

## 主线剧情概要

### 第一章：废土求生（1-30级）

**背景**：2100年，核战争后的废土世界。角色在废墟城市中醒来，失去记忆，需要寻找自己的身世。

**主要事件**：
1. 在废墟城市中求生，学习基本技能
2. 遇到其他幸存者，了解世界现状
3. 发现自己的特殊能力（与宠物沟通）
4. 前往污染荒野，寻找身世线索

**关键选择**：
- 选择加入哪个阵营（影响后续剧情）
- 选择如何对待变异生物（战斗或捕捉）
- 选择探索方向（不同区域有不同剧情）

### 第二章：真相探索（31-60级）

**背景**：深入污染荒野，发现核战争的真相——并非意外，而是阴谋。

**主要事件**：
1. 探索污染荒野，发现古代遗迹
2. 遇到混沌博士的势力，了解其阴谋
3. 发现自己的身世——曾是科学家，参与过核研究
4. 决定对抗混沌博士，保护世界

**关键选择**：
- 选择相信谁（不同角色提供不同信息）
- 选择如何对待混沌博士的势力（战斗或合作）
- 选择是否公开真相（影响世界状态）

### 第三章：对抗混沌（61-90级）

**背景**：混沌博士的势力日益强大，玩家需要联合各方势力对抗。

**主要事件**：
1. 联合各阵营，组建反抗军
2. 攻打混沌博士的据点，削弱其势力
3. 发现混沌博士的真实身份和目的
4. 准备最终决战

**关键选择**：
- 选择战略方向（不同路线有不同难度）
- 选择牺牲谁（某些角色可能牺牲）
- 选择是否使用混沌力量（影响结局）

### 第四章：终极决战（91-100级）

**背景**：进入混沌实验室，与混沌博士进行最终决战。

**主要事件**：
1. 突破混沌实验室的防线
2. 发现混沌博士的真实目的——并非毁灭世界，而是"净化"世界
3. 最终决战，选择如何结束战争
4. 根据选择，不同结局

**关键选择**：
- 选择如何对待混沌博士（杀死、封印、说服）
- 选择是否使用终极力量（影响世界状态）
- 选择世界未来方向（不同结局）

## 支线剧情类型

### 1. 角色支线

| 角色 | 支线数量 | 内容 |
|------|----------|------|
| **同伴角色** | 5+个/人 | 角色个人故事、成长、羁绊 |
| **NPC角色** | 3+个/人 | 角色背景、任务、关系 |
| **敌人角色** | 2+个/人 | 敌人动机、故事、转变 |

### 2. 势力支线

| 势力 | 支线数量 | 内容 |
|------|----------|------|
| **自由联盟** | 5+个 | 保护平民、对抗敌人 |
| **钢铁军团** | 5+个 | 军事行动、战略决策 |
| **自然守护者** | 5+个 | 生态保护、元素研究 |
| **混沌猎手** | 5+个 | 消灭混沌、研究混沌 |

### 3. 探索支线

| 区域 | 支线数量 | 内容 |
|------|----------|------|
| **废墟城市** | 5+个 | 城市秘密、隐藏任务 |
| **污染荒野** | 5+个 | 荒野探索、古代遗迹 |
| **混沌地带** | 5+个 | 混沌研究、危险任务 |
| **混沌实验室** | 5+个 | 最终秘密、终极任务 |
