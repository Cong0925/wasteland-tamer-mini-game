## 🎯 任务类型分类

### 1. 主线任务

| 特性 | 说明 |
|------|------|
| **重要性** | 推进游戏剧情 |
| **数量** | 30+个 |
| **难度** | 中-高 |
| **奖励** | 高额经验、稀有装备、剧情物品 |
| **限制** | 必须按顺序完成 |

### 2. 支线任务

| 特性 | 说明 |
|------|------|
| **重要性** | 补充剧情、提供额外奖励 |
| **数量** | 50+个 |
| **难度** | 低-中 |
| **奖励** | 中等经验、消耗品、材料 |
| **限制** | 部分有前置条件 |

### 3. 日常任务

| 特性 | 说明 |
|------|------|
| **重要性** | 每日重复，提供稳定收益 |
| **数量** | 20+个 |
| **难度** | 低 |
| **奖励** | 少量经验、货币、材料 |
| **限制** | 每日重置 |

### 4. 成就任务

| 特性 | 说明 |
|------|------|
| **重要性** | 达成特定目标 |
| **数量** | 30+个 |
| **难度** | 变化大 |
| **奖励** | 特殊称号、稀有道具 |
| **限制** | 达成条件后自动完成 |

### 5. 世界任务

| 特性 | 说明 |
|------|------|
| **重要性** | 特殊事件，限时完成 |
| **数量** | 10+个 |
| **难度** | 高 |
| **奖励** | 超额奖励、限定道具 |
| **限制** | 限时完成 |

## ⚠️ 任务失败与放弃机制

### 任务失败条件

| 任务类型 | 失败条件 | 说明 |
|----------|----------|------|
| **限时任务** | 超过时间限制 | 任务自动失败 |
| **护送任务** | NPC死亡 | 护送目标死亡 |
| **收集任务** | 放弃任务 | 主动放弃任务 |
| **战斗任务** | 战斗失败 | 被敌人击败 |

### 任务失败惩罚

| 惩罚类型 | 说明 | 影响 |
|----------|------|------|
| **经验惩罚** | 失去已获得的部分经验 | 降低升级速度 |
| **声望惩罚** | 降低与任务发布者的声望 | 影响后续任务 |
| **冷却时间** | 一段时间内无法重新接取 | 影响任务进度 |
| **物品损失** | 失去任务物品 | 需要重新收集 |

### 任务放弃规则

| 规则 | 说明 |
|------|------|
| **放弃限制** | 每天最多放弃3个任务 |
| **放弃惩罚** | 降低任务发布者声望10点 |
| **重新接取** | 24小时后可重新接取 |
| **主线任务** | 主线任务不可放弃 |

### 任务重置机制

| 重置类型 | 重置时间 | 说明 |
|----------|----------|------|
| **日常任务** | 每日0点 | 每天重置 |
| **支线任务** | 不重置 | 完成后永久完成 |
| **主线任务** | 不重置 | 完成后永久完成 |
| **失败任务** | 24小时后 | 可重新接取 |
