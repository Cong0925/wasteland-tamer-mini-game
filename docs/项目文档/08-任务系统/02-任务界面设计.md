# 任务界面设计

> *"界面设计，决定任务体验。"*

---

## 📊 设计统计

| 项目 | 数量 |
|------|------|
| **界面类型** | 5种 |
| **交互方式** | 触摸屏点击 |
| **布局方式** | 竖屏滚动 |
| **按钮数量** | 4-6个 |

---

## 🎮 界面布局原则

### 布局结构

```
┌─────────────────────────────────┐
│           顶部导航栏            │
│    返回 ←  当前位置  → 菜单    │
├─────────────────────────────────┤
│                                 │
│         任务信息区域            │
│   （任务名称、描述、目标）      │
│                                 │
├─────────────────────────────────┤
│                                 │
│         任务目标区域            │
│   （进度条、完成条件）          │
│                                 │
├─────────────────────────────────┤
│                                 │
│         任务奖励区域            │
│   （经验、货币、物品）          │
│                                 │
├─────────────────────────────────┤
│                                 │
│         操作按钮区域            │
│   （接受、放弃、完成）          │
│                                 │
└─────────────────────────────────┘
```

### 设计原则

| 原则 | 说明 |
|------|------|
| **简洁性** | 避免复杂操作 |
| **直观性** | 信息清晰易懂 |
| **可操作性** | 按钮大小适中 |
| **可读性** | 文字清晰易读 |

## 📋 任务列表界面

### 界面布局

```
┌─────────────────────────────────┐
│  ← 返回        任务列表         │
├─────────────────────────────────┤
│                                 │
│  任务数量: 15/20               │
│  已完成: 8个                   │
│  进行中: 7个                   │
│                                 │
├─────────────────────────────────┤
│  任务分类（可点击切换）          │
├─────────────────────────────────┤
│  [全部] [主线] [支线] [日常]    │
│  [成就] [世界]                  │
├─────────────────────────────────┤
│  任务列表（可滚动）             │
├─────────────────────────────────┤
│                                 │
│  ┌─────────────────────────┐   │
│  │ 📜 主线任务              │   │
│  │    探索地下掩体          │   │
│  │    等级要求: 3           │   │
│  │    状态: 进行中          │   │
│  │    进度: 2/5             │   │
│  └─────────────────────────┘   │
│  ┌─────────────────────────┐   │
│  │ 📜 支线任务              │   │
│  │    帮助村民              │   │
│  │    等级要求: 3           │   │
│  │    状态: 可接受          │   │
│  └─────────────────────────┘   │
│  ┌─────────────────────────┐   │
│  │ 📋 日常任务              │   │
│  │    击败10只变异鼠        │   │
│  │    等级要求: 1           │   │
│  │    状态: 进行中          │   │
│  │    进度: 6/10            │   │
│  └─────────────────────────┘   │
│  ┌─────────────────────────┐   │
│  │ 🏆 成就任务              │   │
│  │    探索大师              │   │
│  │    状态: 已完成          │   │
│  │    奖励: 已领取          │   │
│  └─────────────────────────┘   │
│                                 │
└─────────────────────────────────┘
```

### 交互流程

```
打开任务列表
    │
    ▼
显示任务分类标签
    │
    ▼
点击分类标签
    │
    ├── 全部 → 显示所有任务
    ├── 主线 → 只显示主线任务
    ├── 支线 → 只显示支线任务
    ├── 日常 → 只显示日常任务
    ├── 成就 → 只显示成就任务
    └── 世界 → 只显示世界任务
    │
    ▼
显示任务列表
    │
    ▼
点击任务
    │
    ├── 可接受 → 显示任务详情，接受任务
    ├── 进行中 → 显示任务详情，查看进度
    └── 已完成 → 显示任务详情，领取奖励
```
