## BOSS战斗机制

### 1. 阶段转换

| BOSS | 阶段转换条件 | 转换效果 |
|------|--------------|----------|
| 变异狼王 | HP<50% | 进入狂暴状态 |
| 混沌使者 | HP<30% | 使用混沌传送 |
| 混沌将军 | HP<20% | 不屈意志触发 |
| 混沌博士 | HP<50% | 进入第二形态 |
| 混沌核心 | HP<30% | 变异核心激活 |

### 2. 特殊机制

| BOSS | 特殊机制 | 说明 |
|------|----------|------|
| 毒蛇女王 | 毒雾 | 每回合对全体造成中毒伤害 |
| 混沌指挥官 | 军团阵型 | 小兵存活时BOSS防御提升 |
| 混沌将军 | 不屈意志 | HP越低ATK越高 |
| 混沌博士 | 混沌复制 | 可以复制玩家技能 |
| 混沌核心 | 变异核心 | 每3回合释放全屏攻击 |
