## 详细NPC数据

### 老者

| 属性 | 描述 |
|------|------|
| **名称** | 老者 |
| **类型** | 任务NPC |
| **位置** | 废墟城市中心广场 |
| **外观** | 白发苍苍，手持拐杖，眼神深邃 |
| **性格** | 智慧、神秘、关心年轻人 |

#### 对话内容

**初次相遇**：
```
"年轻人，你醒了？你已经昏迷了三天。
这里是废墟城市，2100年的世界。
你...你不记得了吗？"
```

**提供任务**：
```
"你需要找回自己的记忆。
去城市东边的废弃实验室看看，
那里可能有线索。"
```

**闲聊**：
```
"这片废土曾经是繁华的城市。
核战争改变了一切...
我们只能在废墟中求生。"
```

#### 任务列表

| 任务名称 | 任务类型 | 任务内容 | 奖励 |
|----------|----------|----------|------|
| **寻找记忆** | 主线 | 前往废弃实验室 | 经验值+200 |
| **城市探索** | 支线 | 探索城市3个区域 | 经验值+100 |
| **帮助幸存者** | 支线 | 寻找失踪的幸存者 | 经验值+150 |

### 艾米

| 属性 | 描述 |
|------|------|
| **名称** | 艾米 |
| **类型** | 同伴NPC |
| **位置** | 废墟城市东区 |
| **外观** | 年轻女孩，穿着破旧但整洁，眼神坚定 |
| **性格** | 勇敢、善良、有时脆弱 |
| **职业** | 法师 |
| **等级** | 15级 |

#### 角色背景

```
艾米是08号实验体，与玩家（07号实验体）是"兄妹"关系。
她拥有强大的元素能力，但控制力不足。
在废墟城市中长大，失去了大部分记忆。
她相信玩家是她的亲人，愿意为玩家牺牲一切。
```

#### 对话内容

**初次相遇**：
```
"请...请帮帮我...有变异生物在追我..."
（艾米受伤，需要帮助）
```

**加入队伍**：
```
"你...你愿意带我一起吗？
我...我可以帮你战斗。
我有元素能力...虽然控制得不太好。"
```

**闲聊**：
```
"我总是做奇怪的梦...
梦见一个实验室...很多人...
他们叫我08号..."
```

**羁绊对话**（好感度达到一定值）：
```
"无论发生什么...你都是我最重要的人。
我会保护你的...就像你保护我一样。"
```

#### 专属任务

| 任务名称 | 任务类型 | 任务内容 | 奖励 |
|----------|----------|----------|------|
| **记忆碎片** | 角色支线 | 帮助艾米找回记忆 | 艾米好感度+50 |
| **能力觉醒** | 角色支线 | 帮助艾米控制能力 | 艾米能力提升 |
| **过去的真相** | 角色支线 | 确认艾米的记忆 | 羁绊关系确认 |
| **未来选择** | 角色支线 | 帮助艾米做出选择 | 艾米最终形态 |
| **羁绊深化** | 角色支线 | 完成羁绊任务 | 羁绊技能完全体 |

### 杰克

| 属性 | 描述 |
|------|------|
| **名称** | 杰克 |
| **类型** | 同伴NPC |
| **位置** | 废墟城市北区 |
| **外观** | 壮硕男子，穿着军装，眼神坚定 |
| **性格** | 忠诚、勇敢、有时固执 |
| **职业** | 战士 |
| **等级** | 18级 |

#### 角色背景

```
杰克是09号实验体，曾是军人。
在核战争中失去了所有战友，独自幸存。
他拥有强大的战斗能力，但内心孤独。
他相信玩家是他的"兄弟"，愿意为玩家战斗到底。
```

#### 对话内容

**初次相遇**：
```
"你是谁？为什么在这里？
...（观察玩家）...你看起来不像坏人。
需要帮忙吗？"
```

**加入队伍**：
```
"我可以加入你的队伍。
我有战斗经验...可以保护你们。
...（沉默片刻）...我不想再失去同伴了。"
```

**闲聊**：
```
"核战争爆发时，我在前线。
战友们都死了...只有我活了下来。
有时候我在想...为什么是我？"
```

#### 专属任务

| 任务名称 | 任务类型 | 任务内容 | 奖励 |
|----------|----------|----------|------|
| **军人的过去** | 角色支线 | 帮助杰克面对过去 | 杰克好感度+50 |
| **使命与责任** | 角色支线 | 帮助杰克选择 | 杰克技能树解锁 |
| **牺牲精神** | 角色支线 | 阻止或接受杰克的牺牲 | 杰克生死选择 |
| **成长与改变** | 角色支线 | 帮助杰克成长 | 杰克最终形态 |
| **战友的遗产** | 角色支线 | 完成战友的遗愿 | 杰克专属装备 |
