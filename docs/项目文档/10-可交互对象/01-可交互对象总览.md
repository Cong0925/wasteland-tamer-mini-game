# 可交互对象总览

## 系统概述

可交互对象是"末日废土"世界中的重要组成部分，包括NPC、敌人、BOSS等。这些对象为玩家提供任务、战斗、交易、剧情等内容，丰富游戏体验。

## 可交互对象分类

### 1. NPC（非玩家角色）

| 类型 | 数量 | 功能 |
|------|------|------|
| **任务NPC** | 30+个 | 发布任务、提供剧情 |
| **商人NPC** | 20+个 | 交易物品、出售装备 |
| **功能NPC** | 15+个 | 提供服务（修理、强化、治疗等） |
| **同伴NPC** | 5+个 | 加入队伍、协助战斗 |
| **剧情NPC** | 20+个 | 推动剧情、提供信息 |

### 2. 敌人

| 类型 | 数量 | 说明 |
|------|------|------|
| **普通敌人** | 30+种 | 基础敌人，经验丰富 |
| **精英敌人** | 20+种 | 较强敌人，稀有掉落 |
| **元素敌人** | 36种 | 6元素×6变种（鼠/犬/狼/熊/龙/领主），有元素特性 |
| **变异敌人** | 15+种 | 特殊变异，有特殊能力 |

### 3. BOSS

| 类型 | 数量 | 说明 |
|------|------|------|
| **区域BOSS** | 10个 | 分布在各区域：废墟城市3个、污染荒野3个、混沌地带3个、混沌实验室1个 |
| **剧情BOSS** | 5个 | 主线剧情关键BOSS |
| **隐藏BOSS** | 5个 | 特殊条件触发，极高难度 |
| **终极BOSS** | 1个 | 混沌博士，最终决战 |

## 对象交互方式

### 1. NPC交互

| 交互方式 | 说明 | 示例 |
|----------|------|------|
| **对话** | 与NPC交谈获取信息 | 询问任务、了解剧情 |
| **交易** | 与商人NPC交易物品 | 购买/出售物品 |
| **任务** | 接受/完成任务 | 支线任务、日常任务 |
| **服务** | 使用NPC提供的服务 | 修理装备、强化武器 |

### 2. 敌人交互

| 交互方式 | 说明 | 示例 |
|----------|------|------|
| **战斗** | 与敌人进行战斗 | 击败敌人获取奖励 |
| **捕捉** | 捕捉变异生物为宠物 | 使用捕捉球 |
| **逃跑** | 避免战斗 | 逃跑成功率 |

### 3. BOSS交互

| 交互方式 | 说明 | 示例 |
|----------|------|------|
| **挑战** | 挑战BOSS | 需要满足条件 |
| **战斗** | 与BOSS战斗 | 特殊战斗机制 |
| **奖励** | 击败BOSS获取奖励 | 稀有装备、特殊道具 |

## 对象刷新机制

### 刷新时间

| 对象类型 | 刷新时间 | 说明 |
|----------|----------|------|
| **普通敌人** | 5分钟 | 击败后5分钟刷新 |
| **精英敌人** | 30分钟 | 击败后30分钟刷新 |
| **区域BOSS** | 24小时 | 击败后24小时刷新 |
| **剧情BOSS** | 不刷新 | 击败后不再出现 |

### 刷新地点

| 对象类型 | 刷新地点 | 说明 |
|----------|----------|------|
| **普通敌人** | 固定区域 | 在指定区域随机刷新 |
| **精英敌人** | 特定地点 | 在特定地点刷新 |
| **区域BOSS** | BOSS房间 | 在BOSS房间刷新 |
| **剧情BOSS** | 剧情触发点 | 剧情触发后出现 |
