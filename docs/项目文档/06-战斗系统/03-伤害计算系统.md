## 🎯 伤害类型

### 1. 物理伤害

**公式**：

```
物理伤害 = 攻击力 × 技能倍率 × (1 - 防御力/(防御力+100))
```

**示例**：

```
攻击力: 100
技能倍率: 1.5
防御力: 50

物理伤害 = 100 × 1.5 × (1 - 50/(50+100))
         = 150 × (1 - 0.333)
         = 150 × 0.667
         = 100
```

### 2. 特殊伤害

**公式**：

```
特殊伤害 = 技能攻击力 × 技能倍率 × (1 - 特殊防御/(特殊防御+100))
```

**示例**：

```
技能攻击力: 120
技能倍率: 2.0
特殊防御: 30

特殊伤害 = 120 × 2.0 × (1 - 30/(30+100))
         = 240 × (1 - 0.231)
         = 240 × 0.769
         = 185
```

### 3. 范围伤害

**公式**：

```
范围伤害 = 基础伤害 × 范围系数
```

**范围系数**：

| 目标数量 | 范围系数 |
|----------|----------|
| 2个目标 | 0.9 |
| 3个目标 | 0.8 |
| 4个目标 | 0.7 |
| 5个目标 | 0.6 |

### 4. 持续伤害

**公式**：

```
持续伤害 = 基础伤害 × 持续回合数
```

**持续伤害类型**：

| 类型 | 每回合伤害 | 持续时间 |
|------|------------|----------|
| 中毒 | 5%最大HP | 3-5回合 |
| 燃烧 | 8%最大HP | 3-5回合 |
| 流血 | 3%最大HP | 5-7回合 |
| 冻结 | 2%最大HP | 2-3回合 |

### 5. 真实伤害

**公式**：

```
真实伤害 = 固定数值
```

**特点**：
- 无视防御力
- 无视特殊防御
- 固定数值伤害

## 🔥 属性克制系统

### 属性类型

| 属性 | 说明 | 颜色 |
|------|------|------|
| 🔥 火焰 | 火焰攻击 | 红色 |
| ❄️ 冰霜 | 冰霜攻击 | 蓝色 |
| ⚡ 雷电 | 雷电攻击 | 黄色 |
| ☠️ 毒素 | 毒素攻击 | 绿色 |
| ☢️ 辐射 | 辐射攻击 | 紫色 |
| ✨ 净化 | 净化攻击 | 白色 |

### 克制关系

```
🔥 火焰 → ❄️ 冰霜、☠️ 毒素（克制）
🔥 火焰 → ⚡ 雷电、✨ 净化（被克制）

❄️ 冰霜 → ⚡ 雷电、☢️ 辐射（克制）
❄️ 冰霜 → 🔥 火焰、☠️ 毒素（被克制）

⚡ 雷电 → 🔥 火焰、✨ 净化（克制）
⚡ 雷电 → ❄️ 冰霜、☢️ 辐射（被克制）

☠️ 毒素 → ❄️ 冰霜、☢️ 辐射（克制）
☠️ 毒素 → 🔥 火焰、⚡ 雷电（被克制）

☢️ 辐射 → ⚡ 雷电、✨ 净化（克制）
☢️ 辐射 → ❄️ 冰霜、☠️ 毒素（被克制）

✨ 净化 → 🔥 火焰、☠️ 毒素（克制）
✨ 净化 → ⚡ 雷电、☢️ 辐射（被克制）
```

### 克制说明

**设计特点**：本游戏采用**双向互克**设计，即A克制B的同时，B也可能克制A。

**验证规则**：每个元素恰好克制2个、被2个克制，形成平衡的克制网络。

**示例**：
- 火焰克制冰霜和毒素，但被雷电和净化克制
- 冰霜克制雷电和辐射，但被火焰和毒素克制
- 这种设计增加了战斗的策略性，没有绝对强势的元素

### 克制效果

| 关系 | 伤害倍率 | 说明 |
|------|----------|------|
| 克制 | 1.5倍 | 造成额外50%伤害 |
| 被克制 | 0.5倍 | 造成50%伤害 |
| 中立 | 1.0倍 | 正常伤害 |

## 📋 暴击系统

### 暴击公式

```
暴击伤害 = 基础伤害 × 暴击倍率
```

### 暴击倍率

| 暴击等级 | 暴击倍率 |
|----------|----------|
| 普通暴击 | 1.5倍 |
| 强力暴击 | 1.8倍 |
| 极限暴击 | 2.0倍 |
| 致命暴击 | 2.5倍 |

### 暴击率计算

```
暴击率 = 基础暴击率 + 装备暴击率 + 技能暴击率
```

**基础暴击率**：5%

**暴击率上限**：50%

## 🎯 完整伤害计算流程

### 计算步骤

```
1. 基础伤害 = 攻击力 × 技能倍率

2. 属性克制检查
   ├── 克制 → 基础伤害 × 1.5
   ├── 被克制 → 基础伤害 × 0.5
   └── 中立 → 基础伤害 × 1.0

3. 防御减伤
   ├── 物理伤害 → 基础伤害 × (1 - 防御减伤)
   └── 特殊伤害 → 基础伤害 × (1 - 特殊减伤)

4. 暴击检查
   ├── 触发暴击 → 最终伤害 × 暴击倍率
   └── 未触发 → 最终伤害

5. 护盾吸收
   ├── 护盾值 > 最终伤害 → 护盾值 - 最终伤害
   └── 护盾值 < 最终伤害 → HP - (最终伤害 - 护盾值)

6. 最终伤害 = 实际造成的伤害
```

### 计算示例

```
角色属性：
- 攻击力: 100
- 技能倍率: 1.5
- 属性: 火焰

敌人属性：
- 防御力: 50
- 特殊防御: 30
- 属性: 自然

战斗计算：
1. 基础伤害 = 100 × 1.5 = 150
2. 属性克制（火焰克自然）= 150 × 1.5 = 225
3. 防御减伤 = 225 × (1 - 50/150) = 225 × 0.667 = 150
4. 暴击检查（假设未触发）= 150
5. 护盾吸收（假设无护盾）= 150
6. 最终伤害 = 150
```
