## 🎯 技能分类

### 1. 攻击技能

| 类型 | 说明 | MP消耗 | 伤害倍率 |
|------|------|--------|----------|
| **物理攻击** | 基础物理伤害 | 0-10 | 1.0-1.5 |
| **特殊攻击** | 元素/魔法伤害 | 10-30 | 1.5-2.5 |
| **范围攻击** | 同时攻击多个目标 | 15-40 | 0.7-0.9 |
| **单体高伤** | 针对单个目标 | 20-50 | 2.0-3.0 |

### 2. 防御技能

| 类型 | 说明 | MP消耗 | 效果 |
|------|------|--------|------|
| **护盾** | 吸收伤害 | 10-20 | 吸收50-100伤害 |
| **闪避** | 提高闪避率 | 5-15 | 闪避率+30-50% |
| **格挡** | 减少伤害 | 5-10 | 伤害减少50-70% |
| **反击** | 防御后反击 | 15-25 | 防御+反击伤害 |

### 3. 辅助技能

| 类型 | 说明 | MP消耗 | 效果 |
|------|------|--------|------|
| **治疗** | 恢复HP | 10-30 | 恢复30-100HP |
| **增攻** | 提高攻击力 | 10-20 | 攻击力+20-50% |
| **加速** | 提高速度 | 5-15 | 速度+30-50% |
| **净化** | 解除负面状态 | 10-20 | 解除1-2个负面状态 |

### 4. 特殊技能

| 类型 | 说明 | MP消耗 | 效果 |
|------|------|--------|------|
| **控制** | 使敌人无法行动 | 20-40 | 冰霜/眩晕1-2回合 |
| **诅咒** | 降低敌人属性 | 15-30 | 降低20-40%属性 |
| **召唤** | 召唤宠物助战 | 30-50 | 召唤1-2个宠物 |
| **复活** | 复活宠物 | 40-60 | 复活1只宠物 |

## 📊 技能升级系统

### 升级条件

| 条件 | 说明 |
|------|------|
| **使用次数** | 使用技能达到一定次数 |
| **技能等级** | 技能等级提升 |
| **角色等级** | 达到特定等级 |

### 升级效果

| 等级 | 效果提升 | 说明 |
|------|----------|------|
| Lv.1 | 基础效果 | 初始等级 |
| Lv.2 | 伤害/效果+15% | 需要20技能经验 |
| Lv.3 | 伤害/效果+30% | 需要50技能经验 |
| Lv.4 | 伤害/效果+50% | 需要100技能经验 |
| Lv.5 | 伤害/效果+75%，解锁额外效果 | 需要200技能经验 |

**说明**：玩家技能和宠物技能共享同一套升级系统，数值完全一致。

### 技能点获取

| 来源 | 数量 | 说明 |
|------|------|------|
| 角色升级 | 1点/级 | 每升一级获得1点 |
| 任务奖励 | 1-3点 | 特定任务奖励 |
| 成就奖励 | 2-5点 | 达成特定成就 |
