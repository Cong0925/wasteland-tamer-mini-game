# 战斗界面设计

> *"界面设计，决定战斗体验。"*

---

## 📊 设计统计

| 项目 | 数量 |
|------|------|
| **界面类型** | 5种 |
| **交互方式** | 触摸屏点击 |
| **布局方式** | 竖屏滚动 |
| **按钮数量** | 6-8个 |

---

## 🎮 界面布局原则

### 布局结构

```
┌─────────────────────────────────┐
│           顶部导航栏            │
│    返回 ←  当前位置  → 菜单    │
├─────────────────────────────────┤
│                                 │
│         敌人信息区域            │
│   （敌人头像、HP条、状态）      │
│                                 │
├─────────────────────────────────┤
│                                 │
│         战斗日志区域            │
│   （文字描述，可滚动）          │
│                                 │
├─────────────────────────────────┤
│                                 │
│         我方信息区域            │
│   （HP/MP条、状态）             │
│                                 │
├─────────────────────────────────┤
│                                 │
│         选择行动区域            │
│   （可点击按钮，支持滚动）      │
│                                 │
└─────────────────────────────────┘
```

### 设计原则

| 原则 | 说明 |
|------|------|
| **简洁性** | 避免复杂操作 |
| **直观性** | 信息清晰易懂 |
| **可操作性** | 按钮大小适中 |
| **可读性** | 文字清晰易读 |

### 交互流程

```
战斗开始
    │
    ▼
显示敌人信息和战斗日志
    │
    ▼
显示行动按钮
    │
    ▼
玩家点击按钮
    │
    ├── 攻击 → 执行攻击，显示伤害
    ├── 技能 → 打开技能列表，选择技能
    ├── 防御 → 执行防御，显示防御效果
    ├── 道具 → 打开道具列表，选择道具
    ├── 逃跑 → 计算逃跑成功率
    └── 捕捉 → 计算捕捉成功率
    │
    ▼
执行行动，更新战斗日志
    │
    ▼
检查战斗是否结束
    │
    ├── 敌人死亡 → 显示胜利界面
    ├── 我方死亡 → 显示失败界面
    └── 继续战斗 → 回到显示行动按钮
```

### 自动战斗逻辑

```
自动战斗开始
    │
    ▼
检查HP/MP
    │
    ├── HP < 30% → 使用药品
    ├── MP < 20% → 使用普通攻击
    └── 正常 → 选择最优技能
    │
    ▼
执行行动
    │
    ▼
更新战斗日志
    │
    ▼
检查战斗是否结束
    │
    ├── 敌人死亡 → 显示奖励
    ├── 我方死亡 → 显示失败
    └── 继续战斗 → 回到检查HP/MP
```
