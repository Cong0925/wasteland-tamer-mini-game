> *"在这片废土上，战斗是生存的本能。"*

---

## 📊 系统统计

| 项目 | 内容 |
|------|------|
| **战斗类型** | 回合制 + 自动战斗 |
| **操作方式** | 微信小程序触摸屏点击选择 |
| **技能数量** | 50+种 |
| **宠物技能** | 按宠物类型分类 |
| **伤害类型** | 物理、特殊、范围、控制 |

## ⚔️ 战斗类型

### 1. 回合制战斗

| 特性 | 说明 |
|------|------|
| **操作方式** | 每回合选择行动 |
| **策略性** | 高，需要思考 |
| **适合场景** | 精英怪、BOSS战 |
| **界面** | 选项按钮点击选择 |

**回合制流程**：

```
战斗开始
    │
    ▼
选择行动（攻击/技能/防御/道具/逃跑）
    │
    ▼
执行行动
    │
    ▼
敌人行动
    │
    ▼
检查胜负
    │
    ├── 胜利 → 获得奖励
    │
    ├── 失败 → 战斗结束
    │
    └── 继续 → 回到选择行动
```

### 2. 自动战斗

| 特性 | 说明 |
|------|------|
| **操作方式** | 系统自动选择行动 |
| **策略性** | 低，但节省时间 |
| **适合场景** | 刷怪、日常任务 |
| **界面** | 点击"自动战斗"按钮 |

**自动战斗逻辑**：

```
自动战斗开始
    │
    ▼
系统检查HP/MP
    │
    ├── HP低 → 使用药品
    │
    ├── MP低 → 使用普通攻击
    │
    └── 正常 → 选择最优技能
    │
    ▼
执行行动
    │
    ▼
检查战斗是否结束
    │
    ├── 结束 → 显示结果
    │
    └── 继续 → 回到检查HP/MP
```

## 📊 伤害计算公式

### 基础伤害公式

```
物理伤害 = 攻击力 × 技能倍率 × (1 - 防御力/(防御力+100))

特殊伤害 = 技能攻击力 × 技能倍率 × (1 - 特殊防御/(特殊防御+100))

范围伤害 = 基础伤害 × 范围系数 (0.7-0.9)

暴击伤害 = 基础伤害 × 暴击倍率 (1.5-2.0)
```

### 伤害类型

| 类型 | 说明 | 伤害计算 |
|------|------|----------|
| **物理伤害** | 普通攻击、物理技能 | 攻击力×倍率×防御减免 |
| **特殊伤害** | 元素技能、魔法技能 | 技能攻击力×倍率×特殊防御减免 |
| **范围伤害** | 同时攻击多个目标 | 基础伤害×范围系数 |
| **持续伤害** | 中毒、燃烧等 | 每回合固定伤害 |
| **真实伤害** | 无视防御 | 固定数值 |

### 伤害系数

| 系数 | 数值 | 说明 |
|------|------|------|
| **暴击倍率** | 1.5-2.5 | 暴击时伤害倍率（普通1.5/强力1.8/极限2.0/致命2.5） |
| **范围系数** | 0.7-0.9 | 范围攻击伤害系数 |
| **克制系数** | 1.5 | 属性克制时伤害倍率 |
| **被克制系数** | 0.5 | 属性被克制时伤害系数 |

## 🎯 战斗属性

### 基础属性

| 属性 | 说明 | 影响 |
|------|------|------|
| **HP** | 生命值 | 归零则战斗失败 |
| **MP** | 魔法值 | 使用技能消耗 |
| **攻击力** | 物理伤害 | 影响物理伤害 |
| **防御力** | 物理防御 | 减少物理伤害 |
| **技能攻击力** | 特殊伤害 | 影响特殊伤害 |
| **特殊防御** | 特殊防御 | 减少特殊伤害 |
| **速度** | 行动顺序 | 速度高先行动 |
| **暴击率** | 暴击概率 | 影响暴击触发 |
| **闪避率** | 闪避概率 | 影响闪避触发 |

### 状态效果

| 状态 | 效果 | 持续时间 |
|------|------|----------|
| **中毒** | 每回合损失5%HP | 3-5回合 |
| **燃烧** | 每回合损失8%HP | 3-5回合 |
| **冰冻** | 无法行动 | 1-2回合 |
| **麻痹** | 50%概率无法行动 | 2-3回合 |
| **眩晕** | 无法行动 | 1回合 |
| **虚弱** | 攻击力降低30% | 3-5回合 |
| **护盾** | 吸收一定伤害 | 3-5回合 |

## 🐾 宠物战斗系统

### 宠物战斗方式

| 方式 | 说明 |
|------|------|
| **出战** | 宠物参与战斗，可以攻击 |
| **辅助** | 宠物提供增益效果 |
| **待命** | 宠物不参与战斗 |

### 宠物技能分类

| 类型 | 说明 | 示例 |
|------|------|------|
| **攻击技能** | 造成伤害 | 撕咬、爪击、毒液 |
| **防御技能** | 减少伤害 | 护盾、闪避、格挡 |
| **辅助技能** | 增益效果 | 治疗、增攻、加速 |
| **特殊技能** | 特殊效果 | 控制、诅咒、召唤 |

### 宠物技能学习

| 条件 | 说明 |
|------|------|
| **等级要求** | 达到特定等级 |
| **技能书** | 需要对应的技能书 |
| **技能点** | 消耗技能点 |
