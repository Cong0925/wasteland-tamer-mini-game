# 个体差异系统

> *"即使是同一种宠物，也有着不同的天赋。"*

---

## 📊 个体差异概述

### 什么是个体差异？

每只宠物都有独特的个体差异，即使是同一种类、同一等级的宠物，属性也会有所不同。

### 个体差异的作用

- **增加收集乐趣**：追求更高个体值的宠物
- **增加策略性**：不同个体值适合不同玩法
- **增加稀有度**：高个体值宠物更稀有

---

## 🎯 个体值系统

### 个体值范围

| 属性 | 最低值 | 最高值 | 波动范围 |
|------|--------|--------|----------|
| HP | -10% | +10% | 20% |
| 攻击 | -10% | +10% | 20% |
| 防御 | -10% | +10% | 20% |
| 速度 | -10% | +10% | 20% |
| 幸运 | -10% | +10% | 20% |

### 个体值计算

```
实际属性 = 基础属性 × (1 + 个体值/100)

例如：
基础攻击12，个体值+5%
实际攻击 = 12 × 1.05 = 12.6 ≈ 13
```

### 个体值品质

| 品质 | 个体值范围 | 颜色 | 稀有度 |
|------|------------|------|--------|
| 普通 | -10% ~ 0% | 白色 | 常见 |
| 良好 | 0% ~ +5% | 绿色 | 较少 |
| 优秀 | +5% ~ +8% | 蓝色 | 稀有 |
| 完美 | +8% ~ +10% | 紫色 | 极稀有 |

## 🌟 突变系统

### 什么是突变？

突变是宠物的特殊属性加成，有正面突变和负面突变。

### 突变类型

#### 正面突变

| 突变名称 | 效果 | 触发概率 |
|----------|------|----------|
| 强壮 | HP+15% | 5% |
| 狂暴 | 攻击+15% | 5% |
| 坚韧 | 防御+15% | 5% |
| 迅捷 | 速度+15% | 5% |
| 幸运 | 幸运+15% | 5% |
| 全能 | 全属性+5% | 1% |

#### 负面突变

| 突变名称 | 效果 | 触发概率 |
|----------|------|----------|
| 虚弱 | HP-10% | 3% |
| 纤弱 | 攻击-10% | 3% |
| 脆皮 | 防御-10% | 3% |
| 迟钝 | 速度-10% | 3% |
| 倒霉 | 幸运-10% | 3% |

### 突变触发条件

| 条件 | 说明 |
|------|------|
| **捕捉时** | 捕捉宠物时有概率触发突变 |
| **进化时** | 进化时有概率触发新突变 |
| **特殊事件** | 特定剧情事件可能触发突变 |

## 📈 个体差异对战斗的影响

### 战斗力计算

```
实际战斗力 = 基础战斗力 × (1 + 个体值总和/500)

例如：
基础战斗力100，个体值总和+20%
实际战斗力 = 100 × 1.04 = 104
```

### 个体差异示例

| 宠物 | 基础攻击 | 个体值 | 实际攻击 | 差异 |
|------|----------|--------|----------|------|
| 变异狼A | 20 | +8% | 22 | +2 |
| 变异狼B | 20 | -5% | 19 | -1 |
| 变异狼C | 20 | +10% | 22 | +2 |

## 🎮 用户体验

### 查看个体值

```
宠物详情界面：

🐺 变异狼 (Lv.25)
个体值：良好（绿色）

HP：280 (+5%)
攻击：45 (+3%)
防御：32 (+7%)
速度：38 (-2%)
幸运：25 (+10%) ★
```

### 个体值筛选

玩家可以筛选高个体值的宠物：

```
筛选条件：
├── 个体值品质：良好以上
├── 特定属性：攻击+5%以上
└── 突变类型：正面突变
```

## 📊 个体差异与游戏平衡

### 设计原则

| 原则 | 说明 |
|------|------|
| **不影响核心体验** | 个体差异只是锦上添花 |
| **追求极致** | 高个体值是追求目标，非必需 |
| **可替代性** | 低个体值宠物也能通关 |

### 平衡性检查

```
目标：
- 普通玩家：使用普通个体值宠物也能通关
- 追求极致：高个体值宠物有明显优势
- 竞技对战：个体差异影响约10-15%战斗力
```
