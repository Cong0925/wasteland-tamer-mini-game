# 捕捉系统

> *"每一只变异生物，都可能是你最忠实的伙伴。"*

---

## 📊 捕捉系统概述

### 核心机制

```
发现变异生物
      ↓
进入战斗
      ↓
削弱生命值（低于30%）
      ↓
使用捕捉球 + 诱饵
      ↓
计算捕捉概率
      ↓
成功 → 获得宠物
失败 → 继续战斗
```

---

## 🎯 捕捉概率公式

### 基础公式

```
最终捕捉率 = 基础捕捉率 × 球加成 × 诱饵加成 × 幸运加成 × 状态加成

限制：最终捕捉率最高95%，最低5%
```

### 各系数详解

#### 1. 基础捕捉率（稀有度决定）

| 稀有度 | 基础捕捉率 | 设计理由 |
|--------|------------|----------|
| ★ 普通 | 70% | 容易捕捉，新手友好 |
| ★★ 优秀 | 50% | 需要一定策略 |
| ★★★ 稀有 | 30% | 需要准备和运气 |
| ★★★★ 史诗 | 15% | 挑战性高，成就感强 |
| ★★★★★ 传说 | 5% | 极具挑战，稀有珍贵 |

#### 2. 球加成

| 道具 | 加成 | 价格 | 获取方式 |
|------|------|------|----------|
| 标准捕捉球 | +0% | 10结晶 | 商店 |
| 强化捕捉球 | +20% | 30结晶 | 商店 |
| 高级捕捉球 | +40% | 60结晶 | 任务/商店 |
| 大师捕捉球 | +60% | 120结晶 | 稀有掉落 |
| 临时捕捉网 | +10% | 5结晶 | 临时使用 |

#### 3. 诱饵加成

| 诱饵 | 加成 | 适用类型 | 价格 |
|------|------|----------|------|
| 无诱饵 | +0% | - | - |
| 普通诱饵 | +10% | 所有 | 8结晶 |
| 肉干诱饵 | +20% | 哺乳类 | 15结晶 |
| 鱼干诱饵 | +20% | 水生类 | 15结晶 |
| 种子诱饵 | +20% | 鸟类 | 15结晶 |
| 能量糖果 | +15% | 所有 | 20结晶 |

#### 4. 幸运加成

```
幸运加成 = 1 + (玩家幸运值 × 0.005)

例如：
幸运值0 → 加成1.0（+0%）
幸运值20 → 加成1.1（+10%）
幸运值50 → 加成1.25（+25%）
幸运值100 → 加成1.5（+50%）
```

#### 5. 状态加成（HP损失）

| 宠物HP状态 | 加成 | 说明 |
|------------|------|------|
| 100%-70% | +0% | 满血状态 |
| 70%-50% | +10% | 轻伤 |
| 50%-30% | +20% | 中等伤势 |
| 30%-10% | +30% | 重伤（最佳捕捉时机） |
| 10%以下 | +25% | 濒死（可能逃跑） |

## 📝 实际捕捉率示例

### 示例1：捕捉普通变异鼠

| 条件 | 数值 |
|------|------|
| 基础捕捉率 | 70%（★普通） |
| 使用标准捕捉球 | +0% |
| 无诱饵 | +0% |
| 玩家幸运值20 | +10% |
| 宠物HP在50%以下 | +20% |

计算：
```
最终捕捉率 = 70% × 1.0 × 1.0 × 1.1 × 1.2
         = 70% × 1.32
         = 92.4%（限制为92%）
```

### 示例2：捕捉稀有变异狼

| 条件 | 数值 |
|------|------|
| 基础捕捉率 | 30%（★★★稀有） |
| 使用高级捕捉球 | +40% |
| 使用肉干诱饵 | +20% |
| 玩家幸运值50 | +25% |
| 宠物HP在30%以下 | +30% |

计算：
```
最终捕捉率 = 30% × 1.4 × 1.2 × 1.25 × 1.3
         = 30% × 2.73
         = 81.9%（限制为82%）
```

### 示例3：捕捉传说变异凤凰

| 条件 | 数值 |
|------|------|
| 基础捕捉率 | 5%（★★★★★传说） |
| 使用大师捕捉球 | +60% |
| 使用能量糖果 | +15% |
| 玩家幸运值100 | +50% |
| 宠物HP在10%以下 | +25% |

计算：
```
最终捕捉率 = 5% × 1.6 × 1.15 × 1.5 × 1.25
         = 5% × 3.45
         = 17.25%
```

## 🎲 保底机制

### 保底规则

| 规则 | 说明 |
|------|------|
| **保底次数** | 连续捕捉10次失败 |
| **保底效果** | 下次捕捉必中 |
| **触发条件** | 同一只宠物连续捕捉10次 |
| **重置条件** | 捕捉成功或更换目标 |

### 保底提示

```
系统提示：
"你已经尝试捕捉 [宠物名称] 10次了..."
"下次捕捉必定成功！"
```

---

## 📋 捕捉条件

### 基础条件

| 条件 | 说明 |
|------|------|
| **宠物生命值** | 必须低于30% |
| **玩家等级** | 需要达到宠物等级-5 |
| **捕捉次数** | 每次战斗最多捕捉3次（可多次战斗尝试） |
| **背包空间** | 需要有空余位置 |

**说明**：
- "每次战斗最多捕捉3次"是指单次战斗中的限制
- 玩家可以多次战斗尝试捕捉同一只宠物
- 保底计数跨战斗累计（连续10次战斗失败后下次必中）

### 特殊条件

| 宠物类型 | 特殊条件 |
|----------|----------|
| 传说宠物 | 需要完成相关任务 |
| 元素宠物 | 需要在对应元素区域 |
| 混沌宠物 | 需要混沌核心道具 |
| 神兽宠物 | 需要神兽之魂道具 |
