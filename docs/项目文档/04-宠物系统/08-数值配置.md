```

    ├── 1. 修改配置文件

    ├── 2. 上传到服务器
```

## 📊 数据监控指标

### 关键指标

| 指标 | 说明 | 调整方向 |
|------|------|----------|
| **各稀有度捕捉率** | 实际捕捉成功率 | 调整基础概率 |
| **宠物使用率** | 各宠物使用频率 | 调整属性/技能 |
| **进化选择率** | 各进化路线选择 | 调整路线平衡 |
| **技能使用率** | 各技能使用频率 | 调整技能效果 |
| **玩家满意度** | 用户反馈 | 综合调整 |

## 🔧 数值调整接口

### 调整函数

```javascript
// 调整捕捉率
function adjustCaptureRate(rarity, newRate) {
  CAPTURE_CONFIG.baseCaptureRates[rarity] = newRate
}

// 调整宠物属性
function adjustPetStats(petType, stat, newValue) {
  PETS_CONFIG.baseStats[petType][stat] = newValue
}

// 调整技能效果
function adjustSkillDamage(skillId, newMultiplier) {
  SKILLS_CONFIG.damageMultipliers[skillId] = newMultiplier
}
```
