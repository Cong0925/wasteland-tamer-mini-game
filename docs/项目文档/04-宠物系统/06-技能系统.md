> *"技能是战斗的核心，选择正确的技能组合，才能克敌制胜。"*

## 📊 技能分类体系

### 技能类型

```
技能类型
    │
    ├── 攻击技能
    │   ├── 物理攻击：造成物理伤害
    │   ├── 特殊攻击：造成元素/特殊伤害
    │   └── 范围攻击：对多个敌人造成伤害
    │
    ├── 防御技能
    │   ├── 护盾：减少受到的伤害
    │   ├── 闪避：完全躲避攻击
    │   └── 反击：受到攻击时反击
    │
    ├── 辅助技能
    │   ├── 增益：提升自身/队友属性
    │   ├── 治疗：恢复生命值
    │   └── 净化：清除负面状态
    │
    └── 特殊技能
        ├── 控制：眩晕、冰冻、麻痹
        ├── 诅咒：持续伤害、属性削弱
        └── 召唤：召唤帮手
```

### 技能稀有度

| 稀有度 | 说明 | 获取难度 |
|--------|------|----------|
| ★ 普通 | 基础技能 | 初始/低级学习 |
| ★★ 稀有 | 进阶技能 | 中级学习 |
| ★★★ 史诗 | 高级技能 | 高级学习/任务 |
| ★★★★ 传说 | 终极技能 | 进化获得 |

## 🎯 技能学习系统

### 学习方式

| 方式 | 说明 | 限制 |
|------|------|------|
| **初始技能** | 宠物自带 | 1-2个 |
| **升级学习** | 达到特定等级自动学习 | 每5-10级 |
| **技能书学习** | 使用技能书学习 | 需要对应技能书 |
| **进化学习** | 进化后获得新技能 | 进化时自动获得 |

### 技能槽位

**说明**：技能槽位与进化阶段挂钩，进化后解锁更多槽位。

| 进化阶段 | 等级要求 | 技能槽位 | 说明 |
|----------|----------|----------|------|
| 初始 | Lv.1 | 2个 | 基础技能槽 |
| 第一次进化 | Lv.30 | 4个 | 解锁2个新槽位 |
| 第二次进化 | Lv.60 | 6个 | 解锁2个新槽位 |
| 第三次进化 | Lv.90 | 8个 | 解锁2个新槽位 |

## ⚔️ 技能搭配系统

### 搭配类型

| 搭配类型 | 技能组合 | 适用场景 |
|----------|----------|----------|
| **爆发流** | 高伤技能×2 + 增益 | 快速击杀 |
| **持久流** | 攻击技能 + 治疗技能 | 长期战斗 |
| **控制流** | 控制技能×2 + 输出 | 控制敌人 |
| **辅助流** | 增益技能×2 + 治疗 | 团队作战 |

### 搭配示例（猫 - 敏捷型）

```
爆发流搭配：
├── 影袭（高暴击攻击）
├── 疾跑（速度+30%）
└── 闪避（被动闪避）

持久流搭配：
├── 利爪（基础攻击）
├── 潜行（闪避提升）
└── （进化后获得治疗技能）

控制流搭配：
├── 影袭（高暴击）
├── 疾跑（先手）
└── （进化后获得控制技能）
```

## 📊 技能伤害公式

### 物理攻击

```
伤害 = 攻击力 × 技能倍率 × (1 + 暴击加成) × 属性克制

其中：
暴击加成 = 暴击时为0.5，否则为0
属性克制 = 克制时为1.5，被克制时为0.5，正常为1.0
```

### 特殊攻击

```
伤害 = 攻击力 × 技能倍率 × 元素克制 × 随机浮动(0.9-1.1)
```

### 治疗技能

```
治疗量 = 最大HP × 技能倍率 × (1 + 治疗加成)
```
