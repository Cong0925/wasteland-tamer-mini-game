## 📊 属性成长公式

### 基础成长公式

```
属性值 = 基础属性 + (等级 - 1) × 成长系数

其中：
成长系数 = 基础属性 × 0.1（每级成长10%基础属性）
```

## 📈 进化后成长修正

### 修正公式

```
进化后成长系数 = 基础成长系数 × 路线修正 × 物种修正

完整公式：
实际属性值 = 基础属性 + (等级 - 1) × 基础成长系数 × 路线修正 × 物种修正
```

### 修正系数说明

| 修正类型 | 说明 | 示例 |
|----------|------|------|
| **路线修正** | 不同进化路线的属性调整 | 力量型：攻击+30%，速度-20% |
| **物种修正** | 不同物种的成长差异 | 猫：速度+20%，防御-10% |

| 路线 | HP修正 | 攻击修正 | 防御修正 | 速度修正 |

| 🏃 敏捷型 | 0.7 | 0.8 | 0.7 | 1.6 |

### 战斗力公式

```
战斗力 = HP × 0.5 + 攻击 × 2 + 防御 × 1.5 + 速度 × 1 + 幸运 × 0.5
```
